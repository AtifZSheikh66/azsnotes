➕ Addition Theorem of Probability

Probability of the union of events — from two events to n events

Probability Theory · Unit II · Addition Theorem
📜

1. Kolmogorov's Axioms (Foundation)

Axiom 1 (Non-negativity): \( P(E) \geq 0 \) for every event \( E \in \mathcal{F} \)

Axiom 2 (Unit Measure): \( P(\Omega) = 1 \)

Axiom 3 (Countable Additivity): For mutually exclusive events \( E_1, E_2, \ldots \),

\[ P\left( \bigcup_{i=1}^{\infty} E_i \right) = \sum_{i=1}^{\infty} P(E_i) \]

All addition theorems are derived from these three axioms.

➕

2. Addition Theorem for Two Events

📌 Theorem (Addition Rule for Two Events)

\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \]

The probability that either event A or event B (or both) occurs equals the sum of their individual probabilities minus the probability that both occur (to avoid double-counting).

Venn Diagram: \(A \cup B\)

← Union (all shaded areas)

Venn Diagram: \(A \cap B\)

← Intersection (overlap)

📝 Proof of Addition Theorem for Two Events:

Step 1: Express \(A \cup B\) as a union of mutually exclusive events.
\[ A \cup B = (A \cap B^c) \cup (A \cap B) \cup (A^c \cap B) \]

These three sets are pairwise mutually exclusive because:

  • \((A \cap B^c) \cap (A \cap B) = \emptyset\)
  • \((A \cap B^c) \cap (A^c \cap B) = \emptyset\)
  • \((A \cap B) \cap (A^c \cap B) = \emptyset\)
Step 2: Apply Axiom 3 (finite additivity) to the union of mutually exclusive events.
\[ P(A \cup B) = P(A \cap B^c) + P(A \cap B) + P(A^c \cap B) \]
Step 3: Express \(P(A)\) and \(P(B)\) as sums of appropriate parts.
\[ P(A) = P(A \cap B) + P(A \cap B^c) \quad \text{(from Theorem 3a: difference rule)} \]
\[ P(B) = P(A \cap B) + P(A^c \cap B) \quad \text{(from Theorem 3b: difference rule)} \]
Step 4: Add \(P(A)\) and \(P(B)\).
\[ P(A) + P(B) = [P(A \cap B) + P(A \cap B^c)] + [P(A \cap B) + P(A^c \cap B)] \]
\[ P(A) + P(B) = P(A \cap B^c) + P(A^c \cap B) + 2P(A \cap B) \]
Step 5: Rearrange the equation from Step 2.
\[ P(A \cup B) = [P(A \cap B^c) + P(A^c \cap B)] + P(A \cap B) \]
Step 6: Observe that \(P(A \cap B^c) + P(A^c \cap B) = P(A) + P(B) - 2P(A \cap B)\).
\[ \text{Substitute: } P(A \cup B) = [P(A) + P(B) - 2P(A \cap B)] + P(A \cap B) \]
Step 7: Simplify to obtain the addition theorem.
\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \]

📝 Alternative Shorter Proof:

Write \(A \cup B\) as the union of two mutually exclusive events:

\[ A \cup B = A \cup (B \cap A^c) \]

Since \(A\) and \(B \cap A^c\) are mutually exclusive, by Axiom 3:

\[ P(A \cup B) = P(A) + P(B \cap A^c) \]

But \(B \cap A^c = B - (A \cap B)\). Using the difference rule:

\[ P(B \cap A^c) = P(B) - P(A \cap B) \]

Therefore:

\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \]
📌 Corollary 2.1 (Mutually Exclusive Events): If \(A\) and \(B\) are mutually exclusive, then \(P(A \cap B) = 0\), so:
\[ P(A \cup B) = P(A) + P(B) \]
📌 Corollary 2.2 (Union of Complementary Events): Since \(A\) and \(A^c\) are mutually exclusive and \(A \cup A^c = \Omega\):
\[ P(A) + P(A^c) = P(\Omega) = 1 \Rightarrow P(A^c) = 1 - P(A) \]
📌 Corollary 2.3 (Boole's Inequality for Two Events): Since \(P(A \cap B) \geq 0\):
\[ P(A \cup B) \leq P(A) + P(B) \]
📌 Corollary 2.4 (Union Bound): For any events \(A\) and \(B\), the probability of their union is at most the sum of their individual probabilities.
🎨

3. Intuitive Explanation via Venn Diagram

\(P(A) + P(B)\) counts overlap twice

← The overlapping region is included in both \(P(A)\) and \(P(B)\)

Subtract \(P(A \cap B)\) once

← Subtract one copy of the overlap to get correct count

Intuition: When we add \(P(A)\) and \(P(B)\), the outcomes in the intersection \(A \cap B\) are counted twice. The addition theorem subtracts one copy of \(P(A \cap B)\) to count them exactly once.

4. Addition Theorem for Three Events

📌 Theorem (Addition Rule for Three Events)

\[ P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(A \cap C) - P(B \cap C) + P(A \cap B \cap C) \]

The probability that at least one of A, B, or C occurs equals the sum of individual probabilities, minus sum of pairwise intersections, plus the triple intersection.

Venn Diagram: Three Events

← All seven regions (union)

📝 Proof of Addition Theorem for Three Events:

Step 1: Let \(D = B \cup C\). Then \(A \cup B \cup C = A \cup D\).
\[ P(A \cup B \cup C) = P(A \cup D) \]
Step 2: Apply the two-event addition theorem to \(A\) and \(D\).
\[ P(A \cup D) = P(A) + P(D) - P(A \cap D) \]
Step 3: Apply the two-event addition theorem to \(D = B \cup C\).
\[ P(D) = P(B) + P(C) - P(B \cap C) \]
Step 4: Note that \(A \cap D = A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\).
\[ P(A \cap D) = P((A \cap B) \cup (A \cap C)) \]
Step 5: Apply the two-event addition theorem to \((A \cap B)\) and \((A \cap C)\).
\[ P((A \cap B) \cup (A \cap C)) = P(A \cap B) + P(A \cap C) - P((A \cap B) \cap (A \cap C)) \]
\[ \text{But } (A \cap B) \cap (A \cap C) = A \cap B \cap C \]
\[ \text{So } P(A \cap D) = P(A \cap B) + P(A \cap C) - P(A \cap B \cap C) \]
Step 6: Substitute the expressions from Steps 3 and 5 into Step 2.
\[ P(A \cup B \cup C) = P(A) + [P(B) + P(C) - P(B \cap C)] - [P(A \cap B) + P(A \cap C) - P(A \cap B \cap C)] \]
Step 7: Simplify the expression.
\[ P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(B \cap C) - P(A \cap B) - P(A \cap C) + P(A \cap B \cap C) \]
Step 8: Rearrange terms to obtain the final formula.
\[ P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(A \cap C) - P(B \cap C) + P(A \cap B \cap C) \]
📌 Corollary 3.1 (Pairwise Mutually Exclusive Events): If \(A, B, C\) are pairwise mutually exclusive, then all intersections have probability zero, so:
\[ P(A \cup B \cup C) = P(A) + P(B) + P(C) \]
📌 Corollary 3.2 (Boole's Inequality for Three Events): Since all intersection probabilities are non-negative:
\[ P(A \cup B \cup C) \leq P(A) + P(B) + P(C) \]
📌 Corollary 3.3 (Bonferroni Inequalities): The inclusion-exclusion principle gives alternating bounds.
🔢

5. General Addition Theorem for n Events (Inclusion-Exclusion Principle)

📌 Theorem (Inclusion-Exclusion Principle)

\[ P\left( \bigcup_{i=1}^{n} A_i \right) = \sum_{i=1}^{n} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq n} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq n} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{n-1} P\left( \bigcap_{i=1}^{n} A_i \right) \]

In compact form:

\[ P\left( \bigcup_{i=1}^{n} A_i \right) = \sum_{\emptyset \neq J \subseteq \{1,\ldots,n\}} (-1)^{|J|+1} P\left( \bigcap_{j \in J} A_j \right) \]

The probability of the union of n events equals the sum of probabilities of single events, minus sum of pairwise intersections, plus sum of triple intersections, and so on, alternating signs until the n-fold intersection.

📝 Proof of General Addition Theorem for n Events (by Mathematical Induction):

Statement to Prove:
\[ P\left( \bigcup_{i=1}^{n} A_i \right) = \sum_{i=1}^{n} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq n} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq n} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{n-1} P\left( \bigcap_{i=1}^{n} A_i \right) \]
Step 1 — Base Case (n = 1):
\[ P(A_1) = P(A_1) \quad \text{✓ The formula holds trivially.} \]
Step 2 — Base Case (n = 2):
\[ P(A_1 \cup A_2) = P(A_1) + P(A_2) - P(A_1 \cap A_2) \]
\[ \text{This matches the formula: } \sum_{i=1}^{2} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq 2} P(A_i \cap A_j) \]
\[ \text{✓ Base case holds.} \]
Step 3 — Inductive Hypothesis:

Assume that the inclusion-exclusion principle holds for any collection of \(k\) events, where \(k = m\) (for some \(m \geq 2\)). That is:

\[ P\left( \bigcup_{i=1}^{m} A_i \right) = \sum_{i=1}^{m} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{m-1} P\left( \bigcap_{i=1}^{m} A_i \right) \]
Step 4 — Inductive Step (prove for \(n = m+1\) events):

Consider \(m+1\) events \(A_1, A_2, \ldots, A_m, A_{m+1}\). Define:

\[ B = \bigcup_{i=1}^{m} A_i \]

Then the union of all \(m+1\) events can be written as:

\[ \bigcup_{i=1}^{m+1} A_i = B \cup A_{m+1} \]
Step 5 — Apply two-event addition theorem:
\[ P\left( \bigcup_{i=1}^{m+1} A_i \right) = P(B \cup A_{m+1}) = P(B) + P(A_{m+1}) - P(B \cap A_{m+1}) \]
Step 6 — Express \(P(B)\) using the inductive hypothesis:
\[ P(B) = P\left( \bigcup_{i=1}^{m} A_i \right) = \sum_{i=1}^{m} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{m-1} P\left( \bigcap_{i=1}^{m} A_i \right) \]
Step 7 — Express \(B \cap A_{m+1}\):
\[ B \cap A_{m+1} = \left( \bigcup_{i=1}^{m} A_i \right) \cap A_{m+1} = \bigcup_{i=1}^{m} (A_i \cap A_{m+1}) \]

This is the union of \(m\) events. Apply the inductive hypothesis to these \(m\) events \((A_1 \cap A_{m+1}), (A_2 \cap A_{m+1}), \ldots, (A_m \cap A_{m+1})\):

\[ P(B \cap A_{m+1}) = \sum_{i=1}^{m} P(A_i \cap A_{m+1}) - \mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j \cap A_{m+1}) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k \cap A_{m+1}) - \cdots + (-1)^{m-1} P\left( \bigcap_{i=1}^{m} A_i \cap A_{m+1} \right) \]
Step 8 — Substitute \(P(B)\) and \(P(B \cap A_{m+1})\) into the equation from Step 5:
\[ P\left( \bigcup_{i=1}^{m+1} A_i \right) = \left[ \sum_{i=1}^{m} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{m-1} P\left( \bigcap_{i=1}^{m} A_i \right) \right] \]
\[ + P(A_{m+1}) - \left[ \sum_{i=1}^{m} P(A_i \cap A_{m+1}) - \mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j \cap A_{m+1}) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k \cap A_{m+1}) - \cdots + (-1)^{m-1} P\left( \bigcap_{i=1}^{m} A_i \cap A_{m+1} \right) \right] \]
Step 9 — Combine and group like terms:

Single event terms:

\[ \sum_{i=1}^{m} P(A_i) + P(A_{m+1}) = \sum_{i=1}^{m+1} P(A_i) \]

Pairwise intersection terms (two events):

From \(P(B)\) we have: \(- \displaystyle\mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j)\)

From subtracting \(P(B \cap A_{m+1})\) we get: \(- \displaystyle\sum_{i=1}^{m} P(A_i \cap A_{m+1})\)

Combining: \(- \left[ \displaystyle\mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j) + \sum_{i=1}^{m} P(A_i \cap A_{m+1}) \right] = - \displaystyle\mathop{\sum\sum}_{1 \leq i < j \leq m+1} P(A_i \cap A_j)\)

Triple intersection terms (three events):

From \(P(B)\) we have: \(+ \displaystyle\mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k)\)

From subtracting \(P(B \cap A_{m+1})\) we get: \(+ \displaystyle\mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j \cap A_{m+1})\)

Combining: \(+ \left[ \displaystyle\mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m} P(A_i \cap A_j \cap A_k) + \mathop{\sum\sum}_{1 \leq i < j \leq m} P(A_i \cap A_j \cap A_{m+1}) \right] = + \displaystyle\mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m+1} P(A_i \cap A_j \cap A_k)\)

Continuing this pattern: The sign alternates with each higher order of intersection. The last term (intersection of all \(m+1\) events) will have sign \((-1)^{(m+1)-1} = (-1)^m\).

Step 10 — Write the final expression:
\[ P\left( \bigcup_{i=1}^{m+1} A_i \right) = \sum_{i=1}^{m+1} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq m+1} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq m+1} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{m} P\left( \bigcap_{i=1}^{m+1} A_i \right) \]
Step 11 — Conclusion:

Since the formula holds for \(n = 1\) and \(n = 2\), and assuming it holds for \(n = m\), we have proved it holds for \(n = m+1\). Therefore, by the principle of mathematical induction, the inclusion-exclusion principle (general addition theorem) holds for all positive integers \(n\).

\[ \boxed{P\left( \bigcup_{i=1}^{n} A_i \right) = \sum_{i=1}^{n} P(A_i) - \mathop{\sum\sum}_{1 \leq i < j \leq n} P(A_i \cap A_j) + \mathop{\sum\sum\sum}_{1 \leq i < j < k \leq n} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{n-1} P\left( \bigcap_{i=1}^{n} A_i \right)} \]
📌 Corollary 5.1 (Mutually Exclusive Events): If \(A_1, A_2, \ldots, A_n\) are pairwise mutually exclusive, then all intersections have probability zero, so:
\[ P\left( \bigcup_{i=1}^{n} A_i \right) = \sum_{i=1}^{n} P(A_i) \]
📌 Corollary 5.2 (Boole's Inequality): For any finite collection of events:
\[ P\left( \bigcup_{i=1}^{n} A_i \right) \leq \sum_{i=1}^{n} P(A_i) \]
This follows because all intersection terms are subtracted in the inclusion-exclusion, making the right side an upper bound. 📌 Corollary 5.3 (Bonferroni Inequalities): For any \(k\), the partial sums of the inclusion-exclusion series alternately provide upper and lower bounds:
  • First sum (single events): upper bound
  • First sum minus pairwise intersections: lower bound
  • First sum minus pairwise intersections plus triple intersections: upper bound, etc.
📌 Corollary 5.4 (Probability of Union from Complements):
\[ P\left( \bigcup_{i=1}^{n} A_i \right) = 1 - P\left( \bigcap_{i=1}^{n} A_i^c \right) \]
This follows from De Morgan's law and the complement rule.

6. Worked Examples

📖 Example 1: Two Events

In a class of 100 students, 60 study Mathematics (M), 40 study Physics (P), and 20 study both. Find the probability that a randomly selected student studies at least one of the subjects.

Solution:
\(P(M) = 0.6\), \(P(P) = 0.4\), \(P(M \cap P) = 0.2\)
By addition theorem: \(P(M \cup P) = 0.6 + 0.4 - 0.2 = 0.8\) (80 students)
📖 Example 2: Three Events

In a survey of 200 people: 120 like tea (T), 100 like coffee (C), 80 like milk (M), 50 like both tea and coffee, 40 like both tea and milk, 30 like both coffee and milk, and 20 like all three. Find the probability that a randomly selected person likes at least one of the beverages.

Solution:
\(P(T) = 0.6\), \(P(C) = 0.5\), \(P(M) = 0.4\)
\(P(T \cap C) = 0.25\), \(P(T \cap M) = 0.20\), \(P(C \cap M) = 0.15\)
\(P(T \cap C \cap M) = 0.10\)

By addition theorem for three events:
\(P(T \cup C \cup M) = 0.6 + 0.5 + 0.4 - 0.25 - 0.20 - 0.15 + 0.10\)
\(P(T \cup C \cup M) = 1.5 - 0.6 + 0.10 = 1.0\) (all 200 people like at least one beverage)
📖 Example 3: Using Complement Form

If \(P(A) = 0.4\), \(P(B) = 0.3\), and \(P(A \cap B) = 0.1\), find \(P(A^c \cap B^c)\).

Solution:
By De Morgan's law: \(A^c \cap B^c = (A \cup B)^c\)
First find \(P(A \cup B) = 0.4 + 0.3 - 0.1 = 0.6\)
Then \(P(A^c \cap B^c) = 1 - P(A \cup B) = 1 - 0.6 = 0.4\)

7. Practice Problems

Problem 1: For events A and B, if \(P(A) = 0.5\), \(P(B) = 0.4\), and \(P(A \cup B) = 0.7\), find \(P(A \cap B)\).

Show Solution

\(P(A \cup B) = P(A) + P(B) - P(A \cap B) \Rightarrow 0.7 = 0.5 + 0.4 - P(A \cap B) \Rightarrow P(A \cap B) = 0.9 - 0.7 = 0.2\)

Problem 2: Three events A, B, C satisfy: \(P(A) = 0.3\), \(P(B) = 0.4\), \(P(C) = 0.5\), pairwise intersections are 0.1 each, and triple intersection is 0.05. Find \(P(A \cup B \cup C)\).

Show Solution

\(P(A \cup B \cup C) = 0.3 + 0.4 + 0.5 - 0.1 - 0.1 - 0.1 + 0.05 = 1.2 - 0.3 + 0.05 = 0.95\)

Problem 3: Prove that \(P(A \cup B) = 1 - P(A^c \cap B^c)\) using the addition theorem (without using De Morgan's law).

Show Solution

\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\). Also, \(P(A^c \cap B^c) = 1 - P(A \cup B)\) by complement rule, so rearranging gives the result. Alternatively, directly from the complement of the union.

📝 Summary: Key Takeaways

  • Addition Theorem for Two Events: \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)
  • Mutually Exclusive Events: If \(A \cap B = \emptyset\), then \(P(A \cup B) = P(A) + P(B)\)
  • Inclusion-Exclusion for Three Events: \(P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(A \cap C) - P(B \cap C) + P(A \cap B \cap C)\)
  • General Inclusion-Exclusion: Alternating sum over all non-empty subsets: \(P(\bigcup_{i=1}^n A_i) = \sum_{\emptyset \neq J \subseteq \{1,\ldots,n\}} (-1)^{|J|+1} P(\bigcap_{j \in J} A_j)\)
  • Boole's Inequality (Union Bound): \(P(\bigcup_{i=1}^n A_i) \leq \sum_{i=1}^n P(A_i)\)
  • Bonferroni Inequalities: Partial sums of inclusion-exclusion provide alternating bounds
