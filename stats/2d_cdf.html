📐 Two-Dimensional Distribution Function (Joint CDF)

Definition, properties, and proofs for the joint cumulative distribution function

Probability Theory · Unit III · Joint Distribution Function
📜

1. Definition of Joint Distribution Function

The joint cumulative distribution function (joint CDF) of two random variables \(X\) and \(Y\) is defined as:
\[ F_{X,Y}(x, y) = P(X \leq x, Y \leq y), \quad \forall (x, y) \in \mathbb{R}^2 \]

This function gives the probability that \(X\) is at most \(x\) and \(Y\) is at most \(y\) simultaneously.

💡 The joint CDF completely characterizes the joint distribution of \((X, Y)\), capturing all information about the relationship between \(X\) and \(Y\).
📐

2. Properties of the Joint Distribution Function

📌 Property 1: Boundedness

\[ 0 \leq F_{X,Y}(x, y) \leq 1 \quad \text{for all } (x, y) \in \mathbb{R}^2 \]

📝 Proof:

Since \(F_{X,Y}(x,y) = P(X \leq x, Y \leq y)\) is a probability, by the axioms of probability, \(0 \leq P(\cdot) \leq 1\). Hence, \(0 \leq F_{X,Y}(x,y) \leq 1\).

📌 Property 2: Non-decreasing in Each Argument

\[ \text{If } x_1 < x_2 \text{, then } F_{X,Y}(x_1, y) \leq F_{X,Y}(x_2, y) \text{ for fixed } y \]
\[ \text{If } y_1 < y_2 \text{, then } F_{X,Y}(x, y_1) \leq F_{X,Y}(x, y_2) \text{ for fixed } x \]

📝 Proof for \(x\):

If \(x_1 < x_2\), then \(\{X \leq x_1, Y \leq y\} \subseteq \{X \leq x_2, Y \leq y\}\). By monotonicity of probability, the probability of the subset is less than or equal to the probability of the superset:
\[ F_{X,Y}(x_1, y) = P(X \leq x_1, Y \leq y) \leq P(X \leq x_2, Y \leq y) = F_{X,Y}(x_2, y) \]

📌 Property 3: Limits at \(-\infty\)

\[ \lim_{x \to -\infty} F_{X,Y}(x, y) = 0 \quad \text{for any fixed } y \]
\[ \lim_{y \to -\infty} F_{X,Y}(x, y) = 0 \quad \text{for any fixed } x \]
\[ \lim_{x \to -\infty, y \to -\infty} F_{X,Y}(x, y) = 0 \]

📝 Proof:

As \(x \to -\infty\), the event \(\{X \leq x, Y \leq y\}\) approaches the empty set (since no real number is ≤ -∞). By continuity of probability:
\[ \lim_{x \to -\infty} F_{X,Y}(x, y) = P(\emptyset) = 0 \]

📌 Property 4: Marginal CDFs as Limits

\[ \lim_{x \to \infty} F_{X,Y}(x, y) = F_Y(y) = P(Y \leq y) \]
\[ \lim_{y \to \infty} F_{X,Y}(x, y) = F_X(x) = P(X \leq x) \]
\[ \lim_{x \to \infty, y \to \infty} F_{X,Y}(x, y) = 1 \]

📝 Proof:

As \(x \to \infty\), the event \(\{X \leq x, Y \leq y\}\) becomes \(\{Y \leq y\}\). Therefore:
\[ \lim_{x \to \infty} F_{X,Y}(x, y) = P(Y \leq y) = F_Y(y) \]

📌 Property 5: Right-Continuity in Each Argument

\[ \lim_{h \to 0^+} F_{X,Y}(x + h, y) = F_{X,Y}(x, y) \]
\[ \lim_{h \to 0^+} F_{X,Y}(x, y + h) = F_{X,Y}(x, y) \]

📝 Proof:

For a decreasing sequence \(h_n \downarrow 0\), the events \(\{X \leq x + h_n, Y \leq y\}\) decrease to \(\{X \leq x, Y \leq y\}\). By continuity from above:
\[ \lim_{h \to 0^+} F_{X,Y}(x + h, y) = P(X \leq x, Y \leq y) = F_{X,Y}(x, y) \]

📌 Property 6: Probability of a Rectangle

\[ P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F_{X,Y}(x_2, y_2) - F_{X,Y}(x_1, y_2) - F_{X,Y}(x_2, y_1) + F_{X,Y}(x_1, y_1) \]

for any \(x_1 < x_2\) and \(y_1 < y_2\).

📝 Proof:

Step 1 — Use the inclusion-exclusion principle:
\[ P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = P(X \leq x_2, Y \leq y_2) - P(X \leq x_1, Y \leq y_2) - P(X \leq x_2, Y \leq y_1) + P(X \leq x_1, Y \leq y_1) \]
Step 2 — Substitute the definition of joint CDF:
\[ = F_{X,Y}(x_2, y_2) - F_{X,Y}(x_1, y_2) - F_{X,Y}(x_2, y_1) + F_{X,Y}(x_1, y_1) \]

📌 Property 7: Rectangle Inequality

\[ F_{X,Y}(x_2, y_2) - F_{X,Y}(x_1, y_2) - F_{X,Y}(x_2, y_1) + F_{X,Y}(x_1, y_1) \geq 0 \]

📝 Proof:

The left-hand side equals \(P(x_1 < X \leq x_2, y_1 < Y \leq y_2)\), which is a probability and hence non-negative.

📌 Visualization: Rectangle Probability from Joint CDF

For any \(x_1 < x_2\) and \(y_1 < y_2\), the probability that \((X, Y)\) lies in the rectangle \((x_1, x_2] \times (y_1, y_2]\) is:

\[ P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2, y_2) - F(x_1, y_2) - F(x_2, y_1) + F(x_1, y_1) \]

The colored rectangle represents the region \((x_1, x_2] \times (y_1, y_2]\). The joint CDF difference formula gives the probability mass in this region.

📌 Corollary 2.1: The marginal CDFs can be obtained from the joint CDF by taking limits to infinity.

📌 Corollary 2.2: For discrete random variables, the joint PMF can be recovered as:
\[ p_{X,Y}(x_i, y_j) = F_{X,Y}(x_i, y_j) - F_{X,Y}(x_{i-1}, y_j) - F_{X,Y}(x_i, y_{j-1}) + F_{X,Y}(x_{i-1}, y_{j-1}) \]
📌 Corollary 2.3: For continuous random variables, the joint PDF is given by:
\[ f_{X,Y}(x, y) = \frac{\partial^2 F_{X,Y}(x, y)}{\partial x \partial y} \]

5. Worked Examples

📖 Example 1: Continuous Joint CDF
For the uniform distribution on the unit square \([0,1] \times [0,1]\), the joint CDF is:
\[ F_{X,Y}(x,y) = \begin{cases} 0 & x < 0 \text{ or } y < 0 \\ xy & 0 \leq x \leq 1, 0 \leq y \leq 1 \\ x & 0 \leq x \leq 1, y > 1 \\ y & x > 1, 0 \leq y \leq 1 \\ 1 & x > 1, y > 1 \end{cases} \]
📖 Example 2: Probability Calculation
Using the joint CDF table above, find \(P(1 < X \leq 3, 1 < Y \leq 3)\).
\[ = F(3,3) - F(1,3) - F(3,1) + F(1,1) = 1.0 - 0.2 - 0.3 + 0.1 = 0.6 \]

6. Practice Problems

Problem 1: Prove that \(F_{X,Y}(x,y)\) is non-decreasing in both arguments.

Show Solution

If \(x_1 < x_2\), the event \(\{X \leq x_1, Y \leq y\} \subseteq \{X \leq x_2, Y \leq y\}\), so the probability of the subset is less than or equal to the superset.

Problem 2: Use the joint CDF table to find \(P(X \leq 2, Y = 2)\).

Show Solution

\(P(X \leq 2, Y = 2) = F(2,2) - F(2,1) = 0.5 - 0.3 = 0.2\).

Problem 3: For continuous RVs, prove that \(\frac{\partial^2 F_{X,Y}(x,y)}{\partial x \partial y} = f_{X,Y}(x,y)\) wherever the joint PDF exists.

Show Solution

By the definition \(F(x,y) = \int_{-\infty}^x \int_{-\infty}^y f(u,v) dv du\), differentiating with respect to \(x\) and then \(y\) gives \(f(x,y)\) by the Fundamental Theorem of Calculus.

📝 Summary: Key Takeaways

  • Joint CDF Definition: \(F_{X,Y}(x,y) = P(X \leq x, Y \leq y)\)
  • Properties: Bounded \([0,1]\), non-decreasing, right-continuous, limits at \(-\infty\) give 0 and at \(+\infty\) give marginal CDFs
  • Rectangle Probability: \(P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2,y_2) - F(x_1,y_2) - F(x_2,y_1) + F(x_1,y_1)\)
  • Marginals from Joint: \(F_X(x) = \lim_{y \to \infty} F_{X,Y}(x,y)\), \(F_Y(y) = \lim_{x \to \infty} F_{X,Y}(x,y)\)
  • PDF from CDF: \(f_{X,Y}(x,y) = \frac{\partial^2 F_{X,Y}(x,y)}{\partial x \partial y}\) (continuous case)
