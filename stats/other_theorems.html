📚 Other Theorems in Probability

Conditional probability as a probability function, properties, and independence results

Probability Theory · Unit II · Advanced Theorems

1. For Fixed B with \(P(B) > 0\), \(P(A \mid B)\) is a Probability Function

📌 Theorem

For a fixed event \(B\) with \(P(B) > 0\), the function \(P(\cdot \mid B)\) defined by:

\[ P(A \mid B) = \frac{P(A \cap B)}{P(B)} \]

satisfies all three Kolmogorov probability axioms. Hence, \(P(\cdot \mid B)\) is a valid probability measure on the same sample space.

📝 Proof:

Step 1 — Verify Axiom 1 (Non-negativity):

Since \(P(A \cap B) \geq 0\) and \(P(B) > 0\), we have:

\[ P(A \mid B) = \frac{P(A \cap B)}{P(B)} \geq 0 \quad \text{for any event } A \]
Step 2 — Verify Axiom 2 (Unit measure):
\[ P(\Omega \mid B) = \frac{P(\Omega \cap B)}{P(B)} = \frac{P(B)}{P(B)} = 1 \]
Step 3 — Verify Axiom 3 (Countable additivity):

Let \(A_1, A_2, \ldots\) be mutually exclusive events. Then:

\[ P\left( \bigcup_{i=1}^{\infty} A_i \;\middle|\; B \right) = \frac{P\left( \left( \bigcup_{i=1}^{\infty} A_i \right) \cap B \right)}{P(B)} \]
\[ = \frac{P\left( \bigcup_{i=1}^{\infty} (A_i \cap B) \right)}{P(B)} \]

Since the \(A_i\) are mutually exclusive, \(A_i \cap B\) are also mutually exclusive. By Axiom 3 of probability:

\[ = \frac{\sum_{i=1}^{\infty} P(A_i \cap B)}{P(B)} = \sum_{i=1}^{\infty} \frac{P(A_i \cap B)}{P(B)} = \sum_{i=1}^{\infty} P(A_i \mid B) \]
Step 4 — Conclusion:

Thus, \(P(\cdot \mid B)\) satisfies all three probability axioms and is therefore a valid probability measure.

\[ \boxed{P(\cdot \mid B) \text{ is a probability function}} \]
📌 Corollary 1.1: All theorems of probability (addition theorem, complement rule, etc.) hold for conditional probabilities. For example:
\[ P(A^c \mid B) = 1 - P(A \mid B) \]
\[ P(A \cup C \mid B) = P(A \mid B) + P(C \mid B) - P(A \cap C \mid B) \]
📌 Corollary 1.2: The law of total probability can be expressed in terms of conditional probabilities using this property.

2. Addition Theorem for Conditional Probability

📌 Theorem

For any three events \(A, B, C\) with \(P(C) > 0\),

\[ P(A \cup B \mid C) = P(A \mid C) + P(B \mid C) - P(A \cap B \mid C) \]

📝 Proof:

Step 1 — Write the left-hand side using the definition of conditional probability:
\[ P(A \cup B \mid C) = \frac{P((A \cup B) \cap C)}{P(C)} \]
Step 2 — Use the distributive law of sets:
\[ (A \cup B) \cap C = (A \cap C) \cup (B \cap C) \]
Step 3 — Apply the addition theorem for ordinary probability:
\[ P((A \cap C) \cup (B \cap C)) = P(A \cap C) + P(B \cap C) - P((A \cap C) \cap (B \cap C)) \]
Step 4 — Simplify the intersection term:
\[ (A \cap C) \cap (B \cap C) = A \cap B \cap C \]
Step 5 — Substitute back:
\[ P(A \cup B \mid C) = \frac{P(A \cap C) + P(B \cap C) - P(A \cap B \cap C)}{P(C)} \]
Step 6 — Separate the fraction:
\[ = \frac{P(A \cap C)}{P(C)} + \frac{P(B \cap C)}{P(C)} - \frac{P(A \cap B \cap C)}{P(C)} \]
Step 7 — Recognize each term as a conditional probability:
\[ = P(A \mid C) + P(B \mid C) - P(A \cap B \mid C) \]
Step 8 — Conclusion:
\[ \boxed{P(A \cup B \mid C) = P(A \mid C) + P(B \mid C) - P(A \cap B \mid C)} \]
📌 Corollary 2.1: If \(A\) and \(B\) are conditionally independent given \(C\) (i.e., \(P(A \cap B \mid C) = P(A \mid C)P(B \mid C)\)), then:
\[ P(A \cup B \mid C) = P(A \mid C) + P(B \mid C) - P(A \mid C)P(B \mid C) \]
📌 Corollary 2.2: The complement rule for conditional probability follows as a special case:
\[ P(A^c \mid C) = 1 - P(A \mid C) \]

3. Monotonicity of Conditional Probability

📌 Theorem

For any three events \(A, B, C\) defined on the sample space \(S\) such that \(B \subseteq C\) and \(P(A) > 0\),

\[ P(B \mid A) \leq P(C \mid A) \]

📝 Proof:

Step 1 — Write the conditional probabilities explicitly:
\[ P(B \mid A) = \frac{P(B \cap A)}{P(A)}, \quad P(C \mid A) = \frac{P(C \cap A)}{P(A)} \]
Step 2 — Since \(B \subseteq C\), we have \(B \cap A \subseteq C \cap A\):

If \(B\) is a subset of \(C\), then any outcome in \(B \cap A\) is also in \(C \cap A\).

Step 3 — Apply monotonicity of probability (if \(X \subseteq Y\), then \(P(X) \leq P(Y)\)):
\[ P(B \cap A) \leq P(C \cap A) \]
Step 4 — Divide both sides by \(P(A) > 0\):
\[ \frac{P(B \cap A)}{P(A)} \leq \frac{P(C \cap A)}{P(A)} \]
Step 5 — Conclusion:
\[ \boxed{P(B \mid A) \leq P(C \mid A)} \]
📌 Corollary 3.1: For any events \(A, B, C\) with \(P(A) > 0\), if \(B \subseteq C\), then:
\[ P(B \mid A) \leq P(C \mid A) \]
📌 Corollary 3.2: Since \(\emptyset \subseteq B \subseteq S\), we have:
\[ 0 = P(\emptyset \mid A) \leq P(B \mid A) \leq P(S \mid A) = 1 \]

4. Independence of Complements

📌 Theorem

If \(A\) and \(B\) are independent events, then:

\[ \text{(i) } A \text{ and } B^c \text{ are independent} \]
\[ \text{(ii) } A^c \text{ and } B \text{ are independent} \]
\[ \text{(iii) } A^c \text{ and } B^c \text{ are independent} \]

📝 Proof of (i): \(A\) and \(B^c\) are independent:

Step 1 — Write \(A\) as the union of two mutually exclusive events:
\[ A = (A \cap B) \cup (A \cap B^c) \]
Step 2 — Apply the addition rule (since the two sets are mutually exclusive):
\[ P(A) = P(A \cap B) + P(A \cap B^c) \]
Step 3 — Since \(A\) and \(B\) are independent, \(P(A \cap B) = P(A)P(B)\):
\[ P(A) = P(A)P(B) + P(A \cap B^c) \]
Step 4 — Solve for \(P(A \cap B^c)\):
\[ P(A \cap B^c) = P(A) - P(A)P(B) = P(A)[1 - P(B)] = P(A)P(B^c) \]
Step 5 — Conclusion for (i):
\[ \boxed{P(A \cap B^c) = P(A)P(B^c)} \]

Thus, \(A\) and \(B^c\) are independent.

📝 Proof of (ii): \(A^c\) and \(B\) are independent:

By symmetry, swapping the roles of \(A\) and \(B\) in the proof of (i) gives:

\[ P(A^c \cap B) = P(A^c)P(B) \]

📝 Proof of (iii): \(A^c\) and \(B^c\) are independent:

Step 1 — Apply the result of (i) to the events \(A^c\) and \(B\):

From (ii), \(A^c\) and \(B\) are independent. Then by (i) applied to \(A^c\) and \(B\), we get that \(A^c\) and \(B^c\) are independent.

Alternatively, directly:

\[ P(A^c \cap B^c) = P((A \cup B)^c) = 1 - P(A \cup B) \]
Step 2 — Use the addition theorem and independence:
\[ P(A \cup B) = P(A) + P(B) - P(A)P(B) \]
Step 3 — Substitute and simplify:
\[ P(A^c \cap B^c) = 1 - P(A) - P(B) + P(A)P(B) \]
\[ = (1 - P(A))(1 - P(B)) = P(A^c)P(B^c) \]
Step 4 — Conclusion for (iii):
\[ \boxed{P(A^c \cap B^c) = P(A^c)P(B^c)} \]

Thus, \(A^c\) and \(B^c\) are independent.

📌 Corollary 4.1: If \(A\) and \(B\) are independent, then any combination of \(A\) or \(A^c\) with \(B\) or \(B^c\) yields independent events.

📌 Corollary 4.2: This property extends to \(n\) mutually independent events: any combination of each event or its complement yields independent events.

5. \(A \cup B\) and \(C\) are Independent when \(A,B,C\) are Mutually Independent

📌 Theorem

If \(A, B, C\) are mutually independent events, then \(A \cup B\) and \(C\) are also independent.

📝 Proof:

Step 1 — We need to show:
\[ P((A \cup B) \cap C) = P(A \cup B) \cdot P(C) \]
Step 2 — Expand the left-hand side using the distributive law:
\[ (A \cup B) \cap C = (A \cap C) \cup (B \cap C) \]
Step 3 — Apply the addition theorem:
\[ P((A \cup B) \cap C) = P(A \cap C) + P(B \cap C) - P((A \cap C) \cap (B \cap C)) \]
Step 4 — Simplify the intersection:
\[ (A \cap C) \cap (B \cap C) = A \cap B \cap C \]
Step 5 — Use mutual independence of \(A, B, C\):

Since \(A, B, C\) are mutually independent, we have:

\[ P(A \cap C) = P(A)P(C), \quad P(B \cap C) = P(B)P(C), \quad P(A \cap B \cap C) = P(A)P(B)P(C) \]
Step 6 — Substitute these into the expression:
\[ P((A \cup B) \cap C) = P(A)P(C) + P(B)P(C) - P(A)P(B)P(C) \]
\[ = P(C)[P(A) + P(B) - P(A)P(B)] \]
Step 7 — Recognize the bracket as \(P(A \cup B)\) (since \(A\) and \(B\) are independent):
\[ P(A \cup B) = P(A) + P(B) - P(A)P(B) \]
Step 8 — Conclusion:
\[ P((A \cup B) \cap C) = P(A \cup B) \cdot P(C) \]

Therefore, \(A \cup B\) and \(C\) are independent.

\[ \boxed{(A \cup B) \text{ and } C \text{ are independent}} \]
📌 Corollary 5.1: If \(A, B, C\) are mutually independent, then \(A \cap B\) and \(C\) are also independent.

📌 Corollary 5.2: If \(A_1, A_2, \ldots, A_n\) are mutually independent, then any event formed by Boolean operations (union, intersection, complement) on a subset of these events is independent of any event formed on the disjoint complement subset.

6. Condition for Mutual Independence of Three Events

📌 Theorem

If \(A, B, C\) are pairwise independent and \(A\) is independent of \(B \cup C\), then \(A, B, C\) are mutually independent.

📝 Proof:

Step 1 — Given conditions:

We are given:

  • Pairwise independence: \(P(A \cap B) = P(A)P(B)\), \(P(A \cap C) = P(A)P(C)\), \(P(B \cap C) = P(B)P(C)\)
  • \(A\) is independent of \(B \cup C\): \(P(A \cap (B \cup C)) = P(A)P(B \cup C)\)
Step 2 — We need to show mutual independence:

We already have pairwise independence. The only remaining condition for mutual independence of three events is:

\[ P(A \cap B \cap C) = P(A)P(B)P(C) \]
Step 3 — Expand \(P(A \cap (B \cup C))\) in two ways:

First, using the distributive law:

\[ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \]
Step 4 — Apply the addition theorem to the right-hand side:
\[ P(A \cap (B \cup C)) = P(A \cap B) + P(A \cap C) - P(A \cap B \cap C) \]
Step 5 — Substitute the given independence conditions:

From pairwise independence: \(P(A \cap B) = P(A)P(B)\) and \(P(A \cap C) = P(A)P(C)\).

\[ P(A \cap (B \cup C)) = P(A)P(B) + P(A)P(C) - P(A \cap B \cap C) \]
Step 6 — Also, from the independence of \(A\) and \(B \cup C\):
\[ P(A \cap (B \cup C)) = P(A)P(B \cup C) \]
Step 7 — Apply the addition theorem to \(P(B \cup C)\):
\[ P(B \cup C) = P(B) + P(C) - P(B \cap C) \]

Since \(B\) and \(C\) are pairwise independent, \(P(B \cap C) = P(B)P(C)\). Therefore:

\[ P(B \cup C) = P(B) + P(C) - P(B)P(C) \]
Step 8 — Equate the two expressions for \(P(A \cap (B \cup C))\):
\[ P(A)P(B) + P(A)P(C) - P(A \cap B \cap C) = P(A)[P(B) + P(C) - P(B)P(C)] \]
Step 9 — Simplify the right-hand side:
\[ P(A)P(B) + P(A)P(C) - P(A)P(B)P(C) \]
Step 10 — Cancel common terms:

Subtract \(P(A)P(B) + P(A)P(C)\) from both sides:

\[ - P(A \cap B \cap C) = - P(A)P(B)P(C) \]
Step 11 — Multiply both sides by \(-1\):
\[ P(A \cap B \cap C) = P(A)P(B)P(C) \]
Step 12 — Conclusion:

Since we already have pairwise independence and now have triple independence, \(A, B, C\) are mutually independent.

\[ \boxed{A, B, C \text{ are mutually independent}} \]
📌 Corollary 6.1: This theorem provides a sufficient condition to check mutual independence given pairwise independence and independence of \(A\) with \(B \cup C\).

📌 Corollary 6.2: For \(n\) events, similar sufficient conditions can be derived using inclusion-exclusion and the concept of independence of an event with the union of others.
📖 Example: Verifying Mutual Independence
Suppose \(P(A) = P(B) = P(C) = \frac{1}{2}\), \(P(A \cap B) = P(A \cap C) = P(B \cap C) = \frac{1}{4}\) (pairwise independence holds), and also \(P(A \cap (B \cup C)) = \frac{1}{2} \times \frac{3}{4} = \frac{3}{8}\). Then by the theorem, \(A, B, C\) must be mutually independent, which would require \(P(A \cap B \cap C) = \frac{1}{8}\). One can verify that this holds.

7. Practice Problems

Problem 1: Prove that \(P(A \cap B \mid C) = P(A \mid B \cap C) \cdot P(B \mid C)\).

Show Solution

\(P(A \cap B \mid C) = \frac{P(A \cap B \cap C)}{P(C)}\). Also, \(P(A \mid B \cap C) = \frac{P(A \cap B \cap C)}{P(B \cap C)}\) and \(P(B \mid C) = \frac{P(B \cap C)}{P(C)}\). Multiplying: \(P(A \mid B \cap C) \cdot P(B \mid C) = \frac{P(A \cap B \cap C)}{P(B \cap C)} \cdot \frac{P(B \cap C)}{P(C)} = \frac{P(A \cap B \cap C)}{P(C)} = P(A \cap B \mid C)\).

Problem 2: If \(A\) and \(B\) are independent, prove that \(P(A \cup B) = 1 - P(A^c)P(B^c)\).

Show Solution

Since \(A\) and \(B\) are independent, \(A^c\) and \(B^c\) are also independent. Then \(P(A \cup B) = 1 - P(A^c \cap B^c) = 1 - P(A^c)P(B^c)\).

Problem 3: For any three events \(A, B, C\) with \(P(C) > 0\), prove that \(P(A \cup B \mid C) \leq P(A \mid C) + P(B \mid C)\).

Show Solution

From the addition theorem for conditional probability: \(P(A \cup B \mid C) = P(A \mid C) + P(B \mid C) - P(A \cap B \mid C)\). Since \(P(A \cap B \mid C) \geq 0\), the result follows.

📝 Summary: Key Takeaways

  • \(P(\cdot \mid B)\) is a probability function: For fixed \(B\) with \(P(B) > 0\), conditional probability satisfies all three Kolmogorov axioms
  • Addition theorem for conditional probability: \(P(A \cup B \mid C) = P(A \mid C) + P(B \mid C) - P(A \cap B \mid C)\)
  • Monotonicity: If \(B \subseteq C\), then \(P(B \mid A) \leq P(C \mid A)\) (for \(P(A) > 0\))
  • Independence of complements: If \(A\) and \(B\) are independent, then \(A\) and \(B^c\), \(A^c\) and \(B\), and \(A^c\) and \(B^c\) are all independent
  • Union with independent event: If \(A, B, C\) are mutually independent, then \(A \cup B\) is independent of \(C\)
  • Condition for mutual independence: Pairwise independence plus independence of \(A\) from \(B \cup C\) implies mutual independence of \(A, B, C\)
