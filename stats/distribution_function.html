📈 Distribution Function (Cumulative Distribution Function)

Definition, fundamental properties, and proofs of the CDF

Probability Theory · Unit III · Distribution Function
📜

1. Definition of Distribution Function

The Cumulative Distribution Function (CDF) or simply Distribution Function of a random variable \(X\) is defined as:
\[ F_X(x) = P(X \leq x) \quad \text{for all } x \in \mathbb{R} \]

The CDF gives the probability that the random variable \(X\) takes a value less than or equal to \(x\).

Notation: \(F(x)\) is used when the random variable is understood from context.

📖 Example: For a fair die roll, \(X \sim \text{Uniform}\{1,2,3,4,5,6\}\).
\[ F(x) = \begin{cases} 0 & x < 1 \\ \frac{1}{6} & 1 \leq x < 2 \\ \frac{2}{6} & 2 \leq x < 3 \\ \frac{3}{6} & 3 \leq x < 4 \\ \frac{4}{6} & 4 \leq x < 5 \\ \frac{5}{6} & 5 \leq x < 6 \\ 1 & x \geq 6 \end{cases} \]
📐

2. Probability of an Interval: \(P(a < X \leq b) = F(b) - F(a)\)

📌 Theorem (Probability of Half-Open Interval)

For any random variable \(X\) with distribution function \(F\), and for any real numbers \(a < b\),

\[ P(a < X \leq b) = F(b) - F(a) \]

📝 Proof:

Step 1 — Observe that the event \(\{X \leq b\}\) can be partitioned:
\[ \{X \leq b\} = \{X \leq a\} \cup \{a < X \leq b\} \]

These two events are mutually exclusive (disjoint) because \(\{X \leq a\}\) and \(\{a < X \leq b\}\) cannot occur simultaneously.

Step 2 — Apply the addition rule (Axiom 3 of probability):
\[ P(X \leq b) = P(X \leq a) + P(a < X \leq b) \]
Step 3 — Substitute the definition of the CDF:
\[ F(b) = F(a) + P(a < X \leq b) \]
Step 4 — Rearranging gives the result:
\[ P(a < X \leq b) = F(b) - F(a) \]
Step 5 — Conclusion:
\[ \boxed{P(a < X \leq b) = F(b) - F(a)} \]
📌 Corollary 2.1 (Probability of closed interval):
\[ P(a \leq X \leq b) = F(b) - F(a^-) \]
where \(F(a^-) = \lim_{x \to a^-} F(x)\) (left-hand limit).

📌 Corollary 2.2 (Probability of open interval):
\[ P(a < X < b) = F(b^-) - F(a) \]
📌 Corollary 2.3 (Probability of a single point):
\[ P(X = a) = F(a) - F(a^-) \]
This is the size of the jump (discontinuity) at \(a\).
🔢

3. Property 1: \(0 \leq F(x) \leq 1\) for all \(x \in \mathbb{R}\)

📌 Theorem (Bounds of Distribution Function)

For any distribution function \(F\),

\[ 0 \leq F(x) \leq 1 \quad \text{for all } x \in \mathbb{R} \]

📝 Proof:

Step 1 — Lower bound:

Since \(F(x) = P(X \leq x)\) is a probability, by Axiom 1 of probability, all probabilities are non-negative:

\[ F(x) = P(X \leq x) \geq 0 \]
Step 2 — Upper bound:

Since \(\{X \leq x\} \subseteq \Omega\) (the entire sample space), by the monotonicity property of probability:

\[ F(x) = P(X \leq x) \leq P(\Omega) = 1 \]
Step 3 — Conclusion:
\[ \boxed{0 \leq F(x) \leq 1 \quad \forall x \in \mathbb{R}} \]
📌 Corollary 3.1: \(F(x)\) is a bounded function.
📌 Corollary 3.2: For any \(x\), \(F(x) \in [0,1]\).
📈

4. Property 2: \(F(x) \leq F(y)\) if \(x < y\) (Monotonicity)

📌 Theorem (Monotonicity of Distribution Function)

For any \(x, y \in \mathbb{R}\) with \(x < y\),

\[ F(x) \leq F(y) \]

That is, the distribution function is non-decreasing.

📝 Proof:

Step 1 — Observe the set inclusion:

If \(x < y\), then the event \(\{X \leq x\}\) is a subset of the event \(\{X \leq y\}\) because if \(X \leq x\), then certainly \(X \leq y\).

\[ \{X \leq x\} \subseteq \{X \leq y\} \]
Step 2 — Apply monotonicity of probability:

For any two events \(A \subseteq B\), we have \(P(A) \leq P(B)\). Therefore:

\[ P(X \leq x) \leq P(X \leq y) \]
Step 3 — Substitute the definition of \(F\):
\[ F(x) \leq F(y) \]
Step 4 — Conclusion:
\[ \boxed{x < y \implies F(x) \leq F(y)} \]
📌 Corollary 4.1: \(F\) is monotone non-decreasing.
📌 Corollary 4.2: For any \(x\), \(F(x) \geq \lim_{t \to -\infty} F(t)\) and \(F(x) \leq \lim_{t \to \infty} F(t)\).
📌 Corollary 4.3: The function \(F\) has at most countably many discontinuities (since it is monotone).
⬅️

5. Property 3: \(\displaystyle \lim_{x \to -\infty} F(x) = 0\)

📌 Theorem (Limit at \(-\infty\))

\[ \lim_{x \to -\infty} F(x) = 0 \]

📝 Proof:

Step 1 — Consider a decreasing sequence \(x_n \to -\infty\):

Let \(x_1, x_2, x_3, \ldots\) be a sequence such that \(x_n \downarrow -\infty\) (decreasing to \(-\infty\)). Then the events \(A_n = \{X \leq x_n\}\) form a decreasing sequence:

\[ A_1 \supseteq A_2 \supseteq A_3 \supseteq \cdots \]
Step 2 — The limit of the events as \(n \to \infty\):
\[ \lim_{n \to \infty} A_n = \bigcap_{n=1}^{\infty} \{X \leq x_n\} = \emptyset \]

Because as \(x_n \to -\infty\), there is no real number that is simultaneously \(\leq\) all these numbers.

Step 3 — Apply continuity of probability (from above):
\[ \lim_{n \to \infty} P(A_n) = P\left( \lim_{n \to \infty} A_n \right) = P(\emptyset) = 0 \]
Step 4 — Recognize \(P(A_n) = F(x_n)\):
\[ \lim_{x \to -\infty} F(x) = 0 \]
Step 5 — Conclusion:
\[ \boxed{\lim_{x \to -\infty} F(x) = 0} \]
📌 Corollary 5.1: For any \(\epsilon > 0\), there exists \(M\) such that \(F(x) < \epsilon\) for all \(x < M\).
📌 Corollary 5.2: As \(x \to -\infty\), the probability that \(X\) is less than \(x\) becomes arbitrarily small.
➡️

6. Property 4: \(\displaystyle \lim_{x \to \infty} F(x) = 1\)

📌 Theorem (Limit at \(+\infty\))

\[ \lim_{x \to \infty} F(x) = 1 \]

📝 Proof:

Step 1 — Consider an increasing sequence \(x_n \to \infty\):

Let \(x_1, x_2, x_3, \ldots\) be a sequence such that \(x_n \uparrow \infty\) (increasing to \(\infty\)). Then the events \(B_n = \{X \leq x_n\}\) form an increasing sequence:

\[ B_1 \subseteq B_2 \subseteq B_3 \subseteq \cdots \]
Step 2 — The limit of the events as \(n \to \infty\):
\[ \lim_{n \to \infty} B_n = \bigcup_{n=1}^{\infty} \{X \leq x_n\} = \Omega \]

Because as \(x_n \to \infty\), every real number is \(\leq\) some \(x_n\), so the union covers all outcomes.

Step 3 — Apply continuity of probability (from below):
\[ \lim_{n \to \infty} P(B_n) = P\left( \lim_{n \to \infty} B_n \right) = P(\Omega) = 1 \]
Step 4 — Recognize \(P(B_n) = F(x_n)\):
\[ \lim_{x \to \infty} F(x) = 1 \]
Step 5 — Conclusion:
\[ \boxed{\lim_{x \to \infty} F(x) = 1} \]
📌 Corollary 6.1: For any \(\epsilon > 0\), there exists \(M\) such that \(F(x) > 1 - \epsilon\) for all \(x > M\).
📌 Corollary 6.2: As \(x \to \infty\), the probability that \(X\) is less than \(x\) approaches certainty.
🔧

7. Additional Properties of Distribution Functions

📌 Theorem (Right-Continuity)

Every distribution function \(F\) is right-continuous:

\[ \lim_{h \to 0^+} F(x + h) = F(x) \]

📝 Proof of Right-Continuity:

Step 1 — Consider a decreasing sequence \(h_n \downarrow 0\):

Let \(h_n \downarrow 0\). Then the events \(A_n = \{X \leq x + h_n\}\) form a decreasing sequence.

Step 2 — Apply continuity from above:
\[ \lim_{n \to \infty} F(x + h_n) = P\left( \bigcap_{n=1}^{\infty} \{X \leq x + h_n\} \right) = P(X \leq x) = F(x) \]
Step 3 — Since this holds for any decreasing sequence, the right-hand limit is \(F(x)\).
📌 Corollary 7.1: Distribution functions can have jumps (discontinuities), but only from the left.
📌 Corollary 7.2: \(P(X = a) = F(a) - F(a^-)\), where \(F(a^-) = \lim_{x \to a^-} F(x)\) (left-hand limit).
📌 Corollary 7.3: A distribution function is continuous at \(a\) if and only if \(P(X = a) = 0\).
📋

8. Summary of CDF Properties

A function \(F: \mathbb{R} \to [0,1]\) is a cumulative distribution function if and only if it satisfies:

  • P1 (Boundedness): \(0 \leq F(x) \leq 1\) for all \(x \in \mathbb{R}\)
  • P2 (Monotonicity): \(F(x) \leq F(y)\) whenever \(x < y\)
  • P3 (Limit at \(-\infty\)): \(\displaystyle \lim_{x \to -\infty} F(x) = 0\)
  • P4 (Limit at \(+\infty\)): \(\displaystyle \lim_{x \to \infty} F(x) = 1\)
  • P5 (Right-Continuity): \(\displaystyle \lim_{h \to 0^+} F(x + h) = F(x)\) for all \(x\)
📌 Corollary 8.1: Any function satisfying properties P1-P5 is a valid CDF for some random variable.
📌 Corollary 8.2: For discrete random variables, the CDF is a step function with jumps at the possible values.
📌 Corollary 8.3: For continuous random variables, the CDF is continuous everywhere.

9. Worked Examples

📖 Example 1: Discrete Distribution
Let \(X\) be the number of heads in two coin tosses. Find \(F(0.5)\), \(F(1.5)\), and \(F(2.5)\).

Solution:
\[ P(X=0)=\frac{1}{4}, \quad P(X=1)=\frac{1}{2}, \quad P(X=2)=\frac{1}{4} \]
\[ F(0.5) = P(X \leq 0.5) = P(X=0) = \frac{1}{4} \]
\[ F(1.5) = P(X \leq 1.5) = P(X=0)+P(X=1) = \frac{1}{4}+\frac{1}{2} = \frac{3}{4} \]
\[ F(2.5) = P(X \leq 2.5) = P(X=0)+P(X=1)+P(X=2) = 1 \]
📖 Example 2: Continuous Distribution
Let \(X\) be uniformly distributed on \([0,1]\), with \(F(x) = x\) for \(0 \leq x \leq 1\). Find \(P(0.2 < X \leq 0.7)\).

Solution:
\[ P(0.2 < X \leq 0.7) = F(0.7) - F(0.2) = 0.7 - 0.2 = 0.5 \]
📖 Example 3: Finding Probability from CDF
Given \(F(x) = \begin{cases} 0 & x < 0 \\ \frac{x^2}{4} & 0 \leq x < 2 \\ 1 & x \geq 2 \end{cases}\), find \(P(1 < X \leq 1.5)\).

Solution:
\[ P(1 < X \leq 1.5) = F(1.5) - F(1) = \frac{(1.5)^2}{4} - \frac{1^2}{4} = \frac{2.25}{4} - \frac{1}{4} = \frac{1.25}{4} = 0.3125 \]

10. Practice Problems

Problem 1: For a random variable \(X\) with CDF \(F(x)\), show that \(P(X > a) = 1 - F(a)\).

Show Solution

\(P(X > a) = 1 - P(X \leq a) = 1 - F(a)\) by the complement rule.

Problem 2: Prove that \(F(b^-) = \lim_{x \to b^-} F(x) = P(X < b)\).

Show Solution

Consider increasing sequence \(x_n \uparrow b\). Then \(\{X \leq x_n\}\) increases to \(\{X < b\}\). By continuity from below, \(\lim F(x_n) = P(X < b)\).

Problem 3: Given \(F(x) = 1 - e^{-x}\) for \(x \geq 0\) (exponential distribution), find \(P(1 < X \leq 3)\).

Show Solution

\(F(3) - F(1) = (1 - e^{-3}) - (1 - e^{-1}) = e^{-1} - e^{-3} \approx 0.3679 - 0.0498 = 0.3181\)

Problem 4: For any CDF, prove that the set of discontinuity points is at most countable.

Show Solution

Let \(D\) be the set of discontinuity points. For each \(a \in D\), let \(j_a = F(a) - F(a^-) > 0\). Since \(F\) is increasing and bounded by 1, the sum of jumps over any interval is at most 1. Therefore, at most countably many jumps can exceed any threshold \(1/n\), so \(D\) is countable.

📝 Summary: Key Takeaways

  • Definition: \(F(x) = P(X \leq x)\) for all \(x \in \mathbb{R}\)
  • Probability of interval: \(P(a < X \leq b) = F(b) - F(a)\)
  • Property 1 (Boundedness): \(0 \leq F(x) \leq 1\) for all \(x\)
  • Property 2 (Monotonicity): \(F(x) \leq F(y)\) whenever \(x < y\)
  • Property 3 (Limit at \(-\infty\)): \(\lim_{x \to -\infty} F(x) = 0\)
  • Property 4 (Limit at \(+\infty\)): \(\lim_{x \to \infty} F(x) = 1\)
  • Property 5 (Right-Continuity): \(\lim_{h \to 0^+} F(x+h) = F(x)\)
  • Corollary: \(P(X = a) = F(a) - F(a^-)\) (size of jump at \(a\))
