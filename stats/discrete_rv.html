🔢 Discrete Random Variables

Definition, Probability Mass Function, Discrete Distribution Function, and their properties

Probability Theory · Unit III · Discrete Random Variables
📜

1. Definition of a Discrete Random Variable

A random variable \(X\) is said to be discrete if its set of possible values is either finite or countably infinite. That is, there exists a countable set \(\{x_1, x_2, x_3, \ldots\} \subseteq \mathbb{R}\) such that:
\[ P(X = x) > 0 \quad \text{for } x \in \{x_1, x_2, \ldots\} \]
\[ \sum_{i=1}^{\infty} P(X = x_i) = 1 \]

Examples of discrete random variables include:

  • Number of heads in \(n\) coin tosses (Binomial)
  • Number of arrivals at a service station (Poisson)
  • Outcome of rolling a die (Uniform discrete)
  • Number of defective items in a sample (Hypergeometric)
📊

2. Probability Mass Function (PMF)

The Probability Mass Function (PMF) of a discrete random variable \(X\) is defined as:
\[ p_X(x) = P(X = x) \quad \text{for all } x \in \mathbb{R} \]

The PMF specifies the probability that \(X\) takes each specific value in its support.

📌 Properties of Probability Mass Function

A function \(p(x)\) is a valid PMF if and only if it satisfies:

\[ \text{(i)} \quad p(x) \geq 0 \quad \text{for all } x \in \mathbb{R} \]
\[ \text{(ii)} \quad \sum_{x} p(x) = 1 \quad \text{(sum over all possible values)} \]
\[ \text{(iii)} \quad p(x) = 0 \quad \text{for all } x \text{ not in the support} \]

📝 Verification of Properties:

Step 1 — Non-negativity:

Since \(p(x) = P(X = x)\) is a probability, by Axiom 1 of probability, \(P(X = x) \geq 0\). Thus, \(p(x) \geq 0\) for all \(x\).

Step 2 — Summation to 1:

Let \(\{x_1, x_2, \ldots\}\) be the set of possible values of \(X\). The events \(\{X = x_i\}\) are mutually exclusive (since \(X\) can only take one value at a time) and exhaustive (since \(X\) must take some value). Therefore, by countable additivity (Axiom 3):

\[ \sum_{i=1}^{\infty} P(X = x_i) = P\left( \bigcup_{i=1}^{\infty} \{X = x_i\} \right) = P(\Omega) = 1 \]
Step 3 — Zero outside support:

By definition, if \(x\) is not a possible value of \(X\), then \(P(X = x) = 0\). Hence, \(p(x) = 0\) for all \(x\) not in the support.

📌 Corollary 2.1: For any event \(A \subseteq \mathbb{R}\), the probability that \(X \in A\) is:
\[ P(X \in A) = \sum_{x \in A} p(x) \]
📌 Corollary 2.2: The total probability over the support equals 1: \(\sum_{x \in \text{support}} p(x) = 1\).
📈

3. Discrete Distribution Function (CDF)

The Cumulative Distribution Function (CDF) of a discrete random variable \(X\) is defined as:
\[ F_X(x) = P(X \leq x) = \sum_{t \leq x} p(t) \]

For a discrete random variable, the CDF is a right-continuous step function with jumps at the possible values of \(X\).

📌 Properties of Discrete Distribution Function

\[ \text{(i)} \quad 0 \leq F(x) \leq 1 \quad \text{for all } x \]
\[ \text{(ii)} \quad F \text{ is non-decreasing: } x_1 < x_2 \Rightarrow F(x_1) \leq F(x_2) \]
\[ \text{(iii)} \quad \lim_{x \to -\infty} F(x) = 0 \]
\[ \text{(iv)} \quad \lim_{x \to \infty} F(x) = 1 \]
\[ \text{(v)} \quad F \text{ is right-continuous: } \lim_{h \to 0^+} F(x+h) = F(x) \]
\[ \text{(vi)} \quad F \text{ has jump discontinuities at the possible values of } X \]

📝 Verification of Properties:

Step 1 — Boundedness:

Since \(F(x) = P(X \leq x)\) is a probability, \(0 \leq F(x) \leq 1\).

Step 2 — Monotonicity:

If \(x_1 < x_2\), then \(\{X \leq x_1\} \subseteq \{X \leq x_2\}\), so \(F(x_1) \leq F(x_2)\).

Step 3 — Limits:

As \(x \to -\infty\), \(\{X \leq x\} \to \emptyset\), so \(F(x) \to 0\). As \(x \to \infty\), \(\{X \leq x\} \to \Omega\), so \(F(x) \to 1\).

Step 4 — Right-continuity:

For any decreasing sequence \(h_n \downarrow 0\), the events \(\{X \leq x + h_n\}\) decrease to \(\{X \leq x\}\), giving right-continuity.

Step 5 — Jump discontinuities:

At a possible value \(x_j\), \(F(x_j) - F(x_j^-) = P(X = x_j) = p(x_j) > 0\), so there is a jump.

🔗

4. Theorem: \(p(x_j) = P(X = x_j) = F(x_j) - F(x_j^-)\)

📌 Theorem (Relationship between PMF and CDF)

For a discrete random variable \(X\) with possible values \(x_1, x_2, x_3, \ldots\), the probability mass function at \(x_j\) is given by:

\[ p(x_j) = P(X = x_j) = F(x_j) - F(x_j^-) \]

where \(F(x_j^-) = \lim_{x \to x_j^-} F(x)\) is the left-hand limit of the CDF at \(x_j\).

📝 Proof:

Step 1 — Express the probability as a difference of probabilities:
\[ P(X = x_j) = P(X \leq x_j) - P(X < x_j) \]
Step 2 — Identify the first term:
\[ P(X \leq x_j) = F(x_j) \]
Step 3 — Express the second term as a left-hand limit:

For any increasing sequence \(x_n \uparrow x_j\), we have \{X \leq x_n\} \uparrow \{X < x_j\}. By continuity of probability from below:

\[ \lim_{x \to x_j^-} F(x) = \lim_{n \to \infty} F(x_n) = P(X < x_j) \]

Denote this limit as \(F(x_j^-)\).

Step 4 — Substitute into Step 1:
\[ P(X = x_j) = F(x_j) - F(x_j^-) \]
Step 5 — Conclusion:
\[ \boxed{p(x_j) = F(x_j) - F(x_j^-)} \]
📌 Corollary 4.1 (Jump Size): The jump (discontinuity) in the CDF at \(x_j\) equals the probability that \(X = x_j\).

📌 Corollary 4.2 (Reconstruction of PMF from CDF): The PMF can be recovered from the CDF by taking differences at the discontinuity points.

📌 Corollary 4.3 (Probability of an Interval): For any \(a < b\):
\[ P(a < X \leq b) = F(b) - F(a) \]
\[ P(a \leq X \leq b) = F(b) - F(a^-) \]
\[ P(a < X < b) = F(b^-) - F(a) \]

6. Worked Examples

📖 Example 1: Bernoulli Random Variable
Let \(X \sim \text{Bernoulli}(p)\) with \(P(X=1) = p\), \(P(X=0) = 1-p\).
PMF: \(p(0) = 1-p\), \(p(1) = p\)
CDF:
\[ F(x) = \begin{cases} 0 & x < 0 \\ 1-p & 0 \leq x < 1 \\ 1 & x \geq 1 \end{cases} \]
Verify Theorem: \(F(1) - F(1^-) = 1 - (1-p) = p = p(1)\) ✓
📖 Example 2: Binomial Random Variable
Let \(X \sim \text{Binomial}(n=3, p=0.5)\). The PMF is:
\[ p(0)=\frac{1}{8},\; p(1)=\frac{3}{8},\; p(2)=\frac{3}{8},\; p(3)=\frac{1}{8} \]
CDF:
\[ F(x) = \begin{cases} 0 & x < 0 \\ \frac{1}{8} & 0 \leq x < 1 \\ \frac{4}{8} & 1 \leq x < 2 \\ \frac{7}{8} & 2 \leq x < 3 \\ 1 & x \geq 3 \end{cases} \]
Jump sizes: at \(x=1\), \(F(1)-F(1^-) = \frac{4}{8} - \frac{1}{8} = \frac{3}{8} = p(1)\) ✓

7. Practice Problems

Problem 1: A discrete random variable \(X\) has PMF \(p(1)=0.2\), \(p(2)=0.3\), \(p(3)=0.4\), \(p(4)=0.1\). Compute \(F(2.5)\) and \(P(1 < X \leq 3)\).

Show Solution

\(F(2.5) = P(X \leq 2.5) = p(1)+p(2) = 0.2+0.3 = 0.5\).
\(P(1 < X \leq 3) = p(2)+p(3) = 0.3+0.4 = 0.7\).

Problem 2: Given the CDF of a discrete RV: \(F(x) = 0\) for \(x < 0\), \(\frac{1}{4}\) for \(0 \leq x < 1\), \(\frac{3}{4}\) for \(1 \leq x < 2\), \(1\) for \(x \geq 2\). Find the PMF.

Show Solution

\(p(0) = F(0)-F(0^-) = 0.25-0=0.25\)
\(p(1) = F(1)-F(1^-) = 0.75-0.25=0.5\)
\(p(2) = F(2)-F(2^-) = 1-0.75=0.25\)

Problem 3: Prove that for a discrete random variable, \(\sum_{j} F(x_j) - F(x_j^-) = 1\).

Show Solution

\(\sum_j [F(x_j) - F(x_j^-)] = \sum_j p(x_j) = 1\).

📝 Summary: Key Takeaways

  • Discrete Random Variable: Takes values from a finite or countably infinite set
  • Probability Mass Function (PMF): \(p(x) = P(X = x)\) with \(p(x) \geq 0\) and \(\sum_x p(x) = 1\)
  • Discrete Distribution Function (CDF): \(F(x) = P(X \leq x) = \sum_{t \leq x} p(t)\), a right-continuous step function
  • Key Theorem: \(p(x_j) = F(x_j) - F(x_j^-)\) — the jump size equals the PMF value
  • Properties of CDF: Non-decreasing, right-continuous, limits 0 and 1 at ±∞
  • Applications: Bernoulli, Binomial, Poisson, Geometric distributions
