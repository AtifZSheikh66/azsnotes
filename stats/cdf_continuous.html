📈 Cumulative Distribution Function (Continuous Case)

Definition, properties, probability differential, and relationship with PDF

Probability Theory · Unit III · Continuous CDF
📜

1. Definition of Continuous Distribution Function (CDF)

The Cumulative Distribution Function (CDF) of a continuous random variable \(X\) is defined as:
\[ F_X(x) = P(X \leq x) = \int_{-\infty}^{x} f(t) \, dt, \quad \forall x \in \mathbb{R} \]

where \(f(t)\) is the probability density function (PDF) of \(X\). The CDF gives the probability that the random variable takes a value less than or equal to \(x\).

💡 For a continuous random variable, \(F(x)\) is a continuous function (no jumps), unlike the discrete case where it is a step function. This is because \(P(X = a) = 0\) for any specific \(a\).
📐

2. Properties of Continuous Distribution Function

📌 Property 1: Boundedness

\[ 0 \leq F(x) \leq 1 \quad \text{for all } x \in \mathbb{R} \]

📝 Proof:

Since \(F(x) = P(X \leq x)\) is a probability, by the axioms of probability, \(0 \leq P(X \leq x) \leq 1\) for all \(x\). Hence, \(0 \leq F(x) \leq 1\).

📌 Property 2: Monotonicity (Non-decreasing)

\[ x_1 < x_2 \implies F(x_1) \leq F(x_2) \]

📝 Proof:

Step 1 — Observe the set inclusion:

If \(x_1 < x_2\), then \(\{X \leq x_1\} \subseteq \{X \leq x_2\}\).

Step 2 — Apply monotonicity of probability:
\[ P(X \leq x_1) \leq P(X \leq x_2) \]
Step 3 — Therefore:
\[ F(x_1) \leq F(x_2) \]

📌 Property 3: Limit at \(-\infty\)

\[ \lim_{x \to -\infty} F(x) = 0 \]

📝 Proof:

Step 1 — Let \(x_n \to -\infty\) be a decreasing sequence:

Consider \(x_n \downarrow -\infty\). Then the events \(\{X \leq x_n\}\) form a decreasing sequence.

Step 2 — The intersection of these events is empty:
\[ \bigcap_{n=1}^{\infty} \{X \leq x_n\} = \emptyset \]
Step 3 — Apply continuity from above:
\[ \lim_{n \to \infty} P(X \leq x_n) = P(\emptyset) = 0 \]
Step 4 — Therefore:
\[ \lim_{x \to -\infty} F(x) = 0 \]

📌 Property 4: Limit at \(+\infty\)

\[ \lim_{x \to \infty} F(x) = 1 \]

📝 Proof:

Step 1 — Let \(x_n \to \infty\) be an increasing sequence:

Consider \(x_n \uparrow \infty\). Then the events \(\{X \leq x_n\}\) form an increasing sequence.

Step 2 — The union of these events is the entire sample space:
\[ \bigcup_{n=1}^{\infty} \{X \leq x_n\} = \Omega \]
Step 3 — Apply continuity from below:
\[ \lim_{n \to \infty} P(X \leq x_n) = P(\Omega) = 1 \]
Step 4 — Therefore:
\[ \lim_{x \to \infty} F(x) = 1 \]

📌 Property 5: Right-Continuity

\[ \lim_{h \to 0^+} F(x + h) = F(x) \quad \text{for all } x \in \mathbb{R} \]

For continuous random variables, the CDF is actually continuous everywhere (both left and right).

📝 Proof:

Step 1 — Let \(h_n \downarrow 0\) be a decreasing sequence:

Then the events \(\{X \leq x + h_n\}\) decrease to \(\{X \leq x\}\).

Step 2 — Apply continuity from above:
\[ \lim_{h \to 0^+} F(x + h) = P(X \leq x) = F(x) \]

📌 Property 6: Left-Continuity (for Continuous RVs)

\[ \lim_{h \to 0^-} F(x + h) = F(x) \quad \text{for all } x \in \mathbb{R} \]

Unlike discrete random variables, continuous RVs have CDFs that are continuous from the left as well, because \(P(X = x) = 0\).

📝 Proof:

Step 1 — Observe that:
\[ F(x) - F(x^-) = P(X = x) = 0 \]
Step 2 — Hence, left-hand limit equals \(F(x)\):
\[ F(x^-) = \lim_{h \to 0^-} F(x + h) = F(x) \]
📌 Corollary 2.1: For a continuous random variable, the CDF is continuous on all of \(\mathbb{R}\).

📌 Corollary 2.2: \(P(a < X \leq b) = F(b) - F(a)\) for any \(a \leq b\).

📌 Corollary 2.3: \(P(X > a) = 1 - F(a)\).

📌 Corollary 2.4: \(P(X = a) = 0\) for all \(a\).
📊

3. Probability Differential

For a continuous random variable with CDF \(F(x)\) and PDF \(f(x)\), the probability differential is:
\[ dF(x) = f(x) \, dx \]

This represents the infinitesimal probability that \(X\) lies in the infinitesimal interval \([x, x + dx]\):

\[ P(x \leq X \leq x + dx) \approx f(x) \, dx \]

📝 Derivation:

Step 1 — By definition of CDF:
\[ F(x) = \int_{-\infty}^{x} f(t) \, dt \]
Step 2 — Differentiate both sides with respect to \(x\):
\[ \frac{d}{dx} F(x) = f(x) \]
Step 3 — Multiply both sides by \(dx\):
\[ dF(x) = f(x) \, dx \]
Step 4 — Interpretation:
\[ P(x \leq X \leq x + dx) = F(x + dx) - F(x) \approx f(x) \, dx \]
📌 Remark: The probability differential is used in change-of-variable formulas for transformations of continuous random variables.
📐

4. Obtaining PDF from CDF

📌 Theorem 4.1: PDF via Differentiation

If \(F(x)\) is the CDF of a continuous random variable \(X\), then the probability density function is given by:

\[ f(x) = \frac{d}{dx} F(x) \]

at all points where \(F\) is differentiable.

📝 Proof:

Step 1 — By the Fundamental Theorem of Calculus:

Since \(F(x) = \int_{-\infty}^{x} f(t) \, dt\), differentiating both sides with respect to \(x\) yields:

\[ \frac{d}{dx} F(x) = f(x) \]
Step 2 — This holds wherever \(f\) is continuous (which is almost everywhere).
📖 Example: If \(F(x) = \begin{cases} 0 & x < 0 \\ \frac{x^2}{4} & 0 \leq x < 2 \\ 1 & x \geq 2 \end{cases}\), find \(f(x)\).
\[ f(x) = \frac{d}{dx} F(x) = \begin{cases} 0 & x < 0 \\ \frac{x}{2} & 0 < x < 2 \\ 0 & x > 2 \end{cases} \]

At \(x = 0\) and \(x = 2\), \(f(x)\) can be defined arbitrarily (e.g., 0).

📌 Corollary 4.1: The PDF is the derivative of the CDF wherever the derivative exists.

📌 Corollary 4.2: The PDF is the density of the probability mass with respect to the Lebesgue measure.
📐

5. Obtaining CDF from PDF

📌 Theorem 5.1: CDF via Integration

If \(f(x)\) is the PDF of a continuous random variable \(X\), then the cumulative distribution function is given by:

\[ F(x) = \int_{-\infty}^{x} f(t) \, dt \]

📝 Proof:

Step 1 — By definition of PDF, for any \(a \leq b\):
\[ P(a \leq X \leq b) = \int_{a}^{b} f(t) \, dt \]
Step 2 — Set \(a = -\infty\) and \(b = x\):
\[ P(X \leq x) = \int_{-\infty}^{x} f(t) \, dt \]
Step 3 — Therefore:
\[ F(x) = \int_{-\infty}^{x} f(t) \, dt \]
📖 Example: For the exponential distribution with PDF \(f(x) = \lambda e^{-\lambda x}\), \(x \geq 0\), find \(F(x)\).
\[ F(x) = \int_{0}^{x} \lambda e^{-\lambda t} \, dt = 1 - e^{-\lambda x}, \quad x \geq 0 \]

For \(x < 0\), \(F(x) = 0\).

📌 Corollary 5.1: The CDF is the antiderivative (integral) of the PDF.

📌 Corollary 5.2: The area under the PDF curve from \(-\infty\) to \(x\) equals the CDF at \(x\).

📌 Corollary 5.3: \(\lim_{x \to \infty} F(x) = \int_{-\infty}^{\infty} f(t) \, dt = 1\).
🔄

6. Relationship Between PDF and CDF: Summary

The PDF and CDF are related by the following fundamental relationships:

\[ F(x) = \int_{-\infty}^{x} f(t) \, dt \quad \text{(CDF from PDF)} \]
\[ f(x) = \frac{d}{dx} F(x) \quad \text{(PDF from CDF)} \]
\[ P(a \leq X \leq b) = \int_{a}^{b} f(t) \, dt = F(b) - F(a) \]
💡 The PDF is the derivative of the CDF, and the CDF is the integral of the PDF. This is a direct application of the Fundamental Theorem of Calculus.

7. Graphical Representation of PDF and CDF

Below are graphs of the PDF and CDF for the standard normal distribution:
\[ f(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}, \quad F(x) = \int_{-\infty}^{x} \frac{1}{\sqrt{2\pi}} e^{-t^2/2} \, dt \]

📈 Probability Density Function (PDF)

\(f(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}\)

📊 Cumulative Distribution Function (CDF)

\(F(x) = \int_{-\infty}^{x} f(t) dt\)

📖 Observations from the graphs:
  • The PDF is a bell-shaped curve; the total area under it is 1.
  • The CDF is an S-shaped (sigmoid) curve that increases from 0 to 1.
  • The CDF at any \(x\) equals the area under the PDF from \(-\infty\) to \(x\).
  • The slope of the CDF at any point equals the PDF value at that point.

8. Practice Problems

Problem 1: For a continuous random variable with PDF \(f(x) = 3x^2\) for \(0 \leq x \leq 1\), find the CDF \(F(x)\).

Show Solution

\(F(x) = \int_{0}^{x} 3t^2 dt = x^3\) for \(0 \leq x \leq 1\). For \(x < 0\), \(F(x)=0\); for \(x > 1\), \(F(x)=1\).

Problem 2: Given \(F(x) = 1 - e^{-2x}\) for \(x \geq 0\), find the PDF \(f(x)\).

Show Solution

\(f(x) = \frac{d}{dx} F(x) = 2e^{-2x}\) for \(x \geq 0\).

Problem 3: Prove that for any continuous random variable, \(P(a < X < b) = F(b) - F(a)\).

Show Solution

\(P(a < X < b) = P(X \leq b) - P(X \leq a) - P(X = a) + P(X = b)\)? Wait, actually: \(P(a < X < b) = P(X \leq b) - P(X \leq a) - P(X = a) + P(X = b)\)? Simpler: \(F(b) = P(X \leq b) = P(X \leq a) + P(a < X \leq b) = F(a) + P(a < X \leq b)\). Since \(P(a < X \leq b) = P(a < X < b) + P(X = b) = P(a < X < b)\) because \(P(X = b) = 0\). Hence, \(P(a < X < b) = F(b) - F(a)\).

📝 Summary: Key Takeaways

  • CDF Definition: \(F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t) dt\)
  • Properties: \(0 \leq F(x) \leq 1\), non-decreasing, \(\lim_{x \to -\infty} F(x) = 0\), \(\lim_{x \to \infty} F(x) = 1\), and \(F\) is continuous (for continuous RVs)
  • Probability Differential: \(dF(x) = f(x) dx\)
  • Obtaining PDF from CDF: \(f(x) = \frac{d}{dx} F(x)\)
  • Obtaining CDF from PDF: \(F(x) = \int_{-\infty}^{x} f(t) dt\)
  • Probability Formula: \(P(a \leq X \leq b) = F(b) - F(a) = \int_{a}^{b} f(t) dt\)
