📐 Theorems on Probability

Fundamental theorems derived from Kolmogorov's axioms

Probability Theory · Unit II · Core Theorems
📜

1. Kolmogorov's Axioms (Foundation)

Axiom 1 (Non-negativity): \( P(E) \geq 0 \) for every event \( E \in \mathcal{F} \)

Axiom 2 (Unit Measure): \( P(\Omega) = 1 \)

Axiom 3 (Countable Additivity): For mutually exclusive events \( E_1, E_2, \ldots \),

\[ P\left( \bigcup_{i=1}^{\infty} E_i \right) = \sum_{i=1}^{\infty} P(E_i) \]

All the following theorems are derived directly from these three axioms.

∅

2. Theorem 1: Probability of the Impossible Event

📌 Theorem

\[ P(\emptyset) = 0 \]

The probability of the empty set (impossible event) is zero.

📝 Proof:

Note that \( \Omega = \Omega \cup \emptyset \) and \( \Omega \cap \emptyset = \emptyset \). Thus \( \Omega \) and \( \emptyset \) are mutually exclusive.

\[ \text{By Axiom 3 (finite additivity): } P(\Omega) = P(\Omega) + P(\emptyset) \]
\[ 1 = 1 + P(\emptyset) \quad \text{(by Axiom 2)} \]
\[ \Rightarrow P(\emptyset) = 0 \]
📌 Corollary 1.1: The impossible event has probability zero. However, the converse is not necessarily true — an event with probability zero is not always impossible (e.g., continuous distributions).
📌 Corollary 1.2: For any event A, \( P(A \cap A^c) = P(\emptyset) = 0 \).
📌 Corollary 1.3: For any event A, \( P(A \cup A^c) = P(\Omega) = 1 \) by Axiom 2.
🔄

3. Theorem 2: Complement Rule

📌 Theorem

\[ P(A^c) = 1 - P(A) \]

The probability of the complement of an event A is 1 minus the probability of A.

📝 Proof:

We know that \( A \) and \( A^c \) are mutually exclusive and \( A \cup A^c = \Omega \).

\[ \text{By Axiom 3: } P(A \cup A^c) = P(A) + P(A^c) \]
\[ \Rightarrow P(\Omega) = P(A) + P(A^c) \]
\[ \text{By Axiom 2: } 1 = P(A) + P(A^c) \]
\[ \Rightarrow P(A^c) = 1 - P(A) \]
📌 Corollary 2.1: \( P(A) = 1 - P(A^c) \)
📌 Corollary 2.2: For any event A, \( 0 \leq P(A) \leq 1 \) (since \( P(A^c) \geq 0 \) by Axiom 1).
📌 Corollary 2.3: If \( P(A) = 1 \), then \( P(A^c) = 0 \). A is said to occur "almost surely."

4. Theorem 3: Probability of Difference of Events

📌 Theorem 3a

\[ P(A \cap B^c) = P(A) - P(A \cap B) \]

The probability that A occurs but B does not occur equals the probability of A minus the probability of both A and B occurring.

📝 Proof:

Write \( A = (A \cap B) \cup (A \cap B^c) \). These two events are mutually exclusive.

\[ \text{By Axiom 3: } P(A) = P(A \cap B) + P(A \cap B^c) \]
\[ \Rightarrow P(A \cap B^c) = P(A) - P(A \cap B) \]

📌 Theorem 3b

\[ P(A^c \cap B) = P(B) - P(A \cap B) \]

The probability that B occurs but A does not occur equals the probability of B minus the probability of both A and B occurring.

📝 Proof:

Write \( B = (A \cap B) \cup (A^c \cap B) \). These events are mutually exclusive.

\[ \text{By Axiom 3: } P(B) = P(A \cap B) + P(A^c \cap B) \]
\[ \Rightarrow P(A^c \cap B) = P(B) - P(A \cap B) \]
📌 Corollary 3.1: \( P(A \cap B^c) \geq 0 \) (since probabilities are non-negative).
📌 Corollary 3.2: \( P(A \cap B) \leq P(A) \) and \( P(A \cap B) \leq P(B) \) (intersection cannot have probability greater than either individual event).
📌 Corollary 3.3: If \( A \subseteq B \), then \( P(A) \leq P(B) \) (monotonicity property).

5. Theorem 4: Subset Decomposition

📌 Theorem 4a

\[ \text{If } B \subseteq A, \text{ then } P(A) = P(B) + P(A \cap B^c) \]

If B is a subset of A, then the probability of A equals the probability of B plus the probability of A but not B.

📝 Proof:

If \( B \subseteq A \), then we can write \( A = A \cap \Omega = A \cap (B \cup B^c) = (A \cap B) \cup (A \cap B^c) \).

Since \( B \subseteq A \), we have \( A \cap B = B \). Therefore:

\[ A = B \cup (A \cap B^c) \]

These two sets are mutually exclusive (\( B \cap (A \cap B^c) = \emptyset \)).

\[ \text{By Axiom 3: } P(A) = P(B) + P(A \cap B^c) \]

📌 Theorem 4b (Difference Rule from Subset)

\[ \text{If } B \subseteq A, \text{ then } P(A \cap B^c) = P(A) - P(B) \]

📝 Proof:

From Theorem 4a, \( P(A) = P(B) + P(A \cap B^c) \). Rearranging gives the result.

\[ P(A \cap B^c) = P(A) - P(B) \]
📌 Corollary 4.1 (Monotonicity): If \( B \subseteq A \), then \( P(B) \leq P(A) \). This follows because \( P(A \cap B^c) \geq 0 \).
📌 Corollary 4.2: For any events A and B, \( P(A) = P(A \cap B) + P(A \cap B^c) \). This is the general decomposition (without requiring \( B \subseteq A \)).
📌 Corollary 4.3: \( P(A^c \cap B) = P(B) - P(A \cap B) \) (already proved as Theorem 3b).

6. Summary of Theorems and Their Corollaries

📌 Theorem 1 (Impossible Event)

\( P(\emptyset) = 0 \)

Corollaries: Zero-probability events are called "almost impossible"; \( P(A \cap A^c) = 0 \).

📌 Theorem 2 (Complement Rule)

\( P(A^c) = 1 - P(A) \)

Corollaries: \( P(A) = 1 - P(A^c) \); \( 0 \leq P(A) \leq 1 \).

📌 Theorem 3 (Difference Rule)

\( P(A \cap B^c) = P(A) - P(A \cap B) \)
\( P(A^c \cap B) = P(B) - P(A \cap B) \)

Corollaries: \( P(A \cap B) \leq P(A) \); \( P(A \cap B) \leq P(B) \).

📌 Theorem 4 (Subset Decomposition)

\( \text{If } B \subseteq A, \text{ then } P(A) = P(B) + P(A \cap B^c) \)
\( \text{If } B \subseteq A, \text{ then } P(A \cap B^c) = P(A) - P(B) \)

Corollaries: Monotonicity: \( B \subseteq A \Rightarrow P(B) \leq P(A) \).

7. Worked Example

📖 Example: In a class of 100 students, 60 study Mathematics (M), 40 study Physics (P), and 20 study both. Find:
(a) \( P(M \cap P^c) \) — students studying Math only
(b) \( P(M^c \cap P) \) — students studying Physics only
(c) Verify the complement rule for the event "studies at least one subject"

Solution:
Given: \( P(M) = 0.6 \), \( P(P) = 0.4 \), \( P(M \cap P) = 0.2 \)

(a) \( P(M \cap P^c) = P(M) - P(M \cap P) = 0.6 - 0.2 = 0.4 \) (40 students)
(b) \( P(M^c \cap P) = P(P) - P(M \cap P) = 0.4 - 0.2 = 0.2 \) (20 students)
(c) \( P(M \cup P) = P(M) + P(P) - P(M \cap P) = 0.6 + 0.4 - 0.2 = 0.8 \)
Complement of \( M \cup P \) is \( (M \cup P)^c = M^c \cap P^c \).
By complement rule: \( P(M^c \cap P^c) = 1 - P(M \cup P) = 1 - 0.8 = 0.2 \).
Direct calculation: \( P(M^c \cap P^c) = 1 - 0.8 = 0.2 \) ✓

8. Practice Problems

Problem 1: Prove that \( P(A) = P(A \cap B) + P(A \cap B^c) \) directly from the axioms without assuming any subset relationship.

Show Solution

\( A = A \cap \Omega = A \cap (B \cup B^c) = (A \cap B) \cup (A \cap B^c) \). Since \( A \cap B \) and \( A \cap B^c \) are mutually exclusive, by Axiom 3: \( P(A) = P(A \cap B) + P(A \cap B^c) \).

Problem 2: If \( P(A) = 0.7 \) and \( P(A \cup B) = 0.9 \), what is \( P(A^c \cap B) \)?

Show Solution

\( P(A \cup B) = P(A) + P(B) - P(A \cap B) \). Also, \( P(A^c \cap B) = P(B) - P(A \cap B) = P(A \cup B) - P(A) = 0.9 - 0.7 = 0.2 \).

Problem 3: Using the complement rule, prove that \( P(A \cup B) = 1 - P(A^c \cap B^c) \).

Show Solution

By De Morgan's law, \( (A \cup B)^c = A^c \cap B^c \). Then applying the complement rule: \( P(A \cup B) = 1 - P((A \cup B)^c) = 1 - P(A^c \cap B^c) \).

📝 Summary: Key Takeaways

  • All probability theorems are derived from Kolmogorov's three axioms
  • Impossible event: \( P(\emptyset) = 0 \) (but zero probability does not imply impossibility in continuous spaces)
  • Complement rule: \( P(A^c) = 1 - P(A) \) — fundamental for finding probabilities of "not" events
  • Difference rule: \( P(A \cap B^c) = P(A) - P(A \cap B) \) — isolates the part of A that does not overlap with B
  • Monotonicity: If \( B \subseteq A \), then \( P(B) \leq P(A) \)
  • Every theorem has corollaries — important consequences that extend applicability
