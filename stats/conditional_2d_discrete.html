📊 Conditional Probability Function (Discrete Case)

Definition, properties, and visualization for two-dimensional discrete random variables

Probability Theory · Unit III · Conditional Distributions
📜

1. Definition of Conditional Probability Function (Conditional PMF)

For two discrete random variables \(X\) and \(Y\) with joint probability mass function \(p_{X,Y}(x,y)\) and marginal PMFs \(p_X(x)\) and \(p_Y(y)\), the conditional probability mass function of \(X\) given \(Y = y\) is defined as:
\[ p_{X|Y}(x \mid y) = P(X = x \mid Y = y) = \frac{p_{X,Y}(x,y)}{p_Y(y)}, \quad \text{provided } p_Y(y) > 0 \]

Similarly, the conditional probability mass function of \(Y\) given \(X = x\) is:

\[ p_{Y|X}(y \mid x) = P(Y = y \mid X = x) = \frac{p_{X,Y}(x,y)}{p_X(x)}, \quad \text{provided } p_X(x) > 0 \]
💡 Interpretation: The conditional PMF gives the probability distribution of one random variable when the other is known to have taken a specific value.
📐

2. Properties of Conditional Probability Function

📌 Property 1: Non-negativity

\[ p_{X|Y}(x \mid y) \geq 0 \quad \text{for all } x, y \]

📝 Proof:

Since \(p_{X,Y}(x,y) \geq 0\) and \(p_Y(y) > 0\), their quotient is non-negative.

📌 Property 2: Summation to 1

\[ \sum_{x} p_{X|Y}(x \mid y) = 1 \quad \text{for each fixed } y \text{ with } p_Y(y) > 0 \]

📝 Proof:

Step 1 — Write the sum definition:
\[ \sum_{x} p_{X|Y}(x \mid y) = \sum_{x} \frac{p_{X,Y}(x,y)}{p_Y(y)} \]
Step 2 — Factor out \(1/p_Y(y)\):
\[ = \frac{1}{p_Y(y)} \sum_{x} p_{X,Y}(x,y) \]
Step 3 — Recognize the marginal PMF:
\[ \sum_{x} p_{X,Y}(x,y) = p_Y(y) \]
Step 4 — Substitute:
\[ = \frac{1}{p_Y(y)} \cdot p_Y(y) = 1 \]

📌 Property 3: Multiplication Rule (Reconstruction of Joint PMF)

\[ p_{X,Y}(x,y) = p_{X|Y}(x \mid y) \cdot p_Y(y) = p_{Y|X}(y \mid x) \cdot p_X(x) \]

📝 Proof:

Directly from the definition of conditional PMF:
\[ p_{X|Y}(x \mid y) \cdot p_Y(y) = \frac{p_{X,Y}(x,y)}{p_Y(y)} \cdot p_Y(y) = p_{X,Y}(x,y) \]

📌 Property 4: Law of Total Probability (Discrete Version)

\[ p_X(x) = \sum_{y} p_{X|Y}(x \mid y) \cdot p_Y(y) \]

📝 Proof:

Step 1 — Start with the marginal PMF:
\[ p_X(x) = \sum_{y} p_{X,Y}(x,y) \]
Step 2 — Substitute the multiplication rule:
\[ p_X(x) = \sum_{y} p_{X|Y}(x \mid y) \cdot p_Y(y) \]
📌 Corollary 2.1: For each fixed \(y\), the function \(x \mapsto p_{X|Y}(x \mid y)\) is a valid probability mass function.

📌 Corollary 2.2: Conditional PMFs satisfy all the axioms of probability.

📌 Corollary 2.3 (Bayes' Theorem for Discrete RVs):
\[ p_{X|Y}(x \mid y) = \frac{p_{Y|X}(y \mid x) \cdot p_X(x)}{\sum_{x'} p_{Y|X}(y \mid x') \cdot p_X(x')} \]

5. Relationship with Independence

📌 Theorem: Independence and Conditional PMF

\(X\) and \(Y\) are independent if and only if the conditional PMF equals the marginal PMF:

\[ p_{X|Y}(x \mid y) = p_X(x) \quad \text{for all } x, y \text{ with } p_Y(y) > 0 \]

Equivalently, \(p_{Y|X}(y \mid x) = p_Y(y)\) for all \(x, y\) with \(p_X(x) > 0\).

📝 Proof (⇒ Direction):

If \(X\) and \(Y\) are independent, then:
\[ p_{X,Y}(x,y) = p_X(x) \cdot p_Y(y) \]
Then:
\[ p_{X|Y}(x \mid y) = \frac{p_X(x) p_Y(y)}{p_Y(y)} = p_X(x) \]

📝 Proof (⇐ Direction):

If \(p_{X|Y}(x \mid y) = p_X(x)\), then:
\[ p_{X,Y}(x,y) = p_{X|Y}(x \mid y) \cdot p_Y(y) = p_X(x) \cdot p_Y(y) \]
📌 Corollary 5.1: If \(X\) and \(Y\) are independent, then \(p_{X|Y}(x \mid y)\) does not depend on \(y\).

📌 Corollary 5.2: Conditional distributions are identical for all conditioning values when independence holds.

6. Worked Examples

📖 Example 1: Two Dice Roll (Independent)

Let \(X\) and \(Y\) be outcomes of two independent fair dice. Find \(p_{X|Y}(x \mid y)\).

Solution: Since \(X\) and \(Y\) are independent, \(p_{X|Y}(x \mid y) = p_X(x) = \frac{1}{6}\) for all \(x, y\).

📖 Example 2: Sampling Without Replacement

From a box with 3 defective and 2 good items, two items are drawn without replacement. Let \(X\) = number of defectives in first draw, \(Y\) = number of defectives in second draw. Find \(p_{Y|X}(y \mid x = 1)\).

Solution: The joint PMF table is:

\(p_Y(y)\)0.40.61
\[ p_{Y|X}(0 \mid 1) = \frac{p(1,0)}{p_X(1)} = \frac{0.3}{0.6} = 0.5 \]
\[ p_{Y|X}(1 \mid 1) = \frac{0.3}{0.6} = 0.5 \]

7. Practice Problems

Problem 1: Using the joint PMF table in Section 3, find \(p_{X|Y}(2 \mid 3)\) and \(p_{Y|X}(2 \mid 2)\).

Show Solution

\(p_{X|Y}(2 \mid 3) = \frac{0.1}{0.3} = \frac{1}{3} \approx 0.333\)
\(p_{Y|X}(2 \mid 2) = \frac{0.1}{0.4} = 0.25\)

Problem 2: Prove that \(p_{X,Y}(x,y) = p_{X|Y}(x \mid y) p_Y(y)\).

Show Solution

This follows directly from the definition of conditional PMF: multiply both sides of \(p_{X|Y}(x \mid y) = p_{X,Y}(x,y)/p_Y(y)\) by \(p_Y(y)\).

Problem 3: If \(X\) and \(Y\) are independent, show that \(p_{X|Y}(x \mid y) = p_X(x)\).

Show Solution

By independence, \(p_{X,Y}(x,y) = p_X(x)p_Y(y)\). Then \(p_{X|Y}(x \mid y) = p_X(x)p_Y(y)/p_Y(y) = p_X(x)\).

📝 Summary: Key Takeaways

  • Conditional PMF Definition: \(p_{X|Y}(x \mid y) = \frac{p_{X,Y}(x,y)}{p_Y(y)}\) for \(p_Y(y) > 0\)
  • Properties: Non-negative, sums to 1 for each fixed \(y\), valid probability mass function
  • Multiplication Rule: \(p_{X,Y}(x,y) = p_{X|Y}(x \mid y) p_Y(y) = p_{Y|X}(y \mid x) p_X(x)\)
  • Law of Total Probability: \(p_X(x) = \sum_y p_{X|Y}(x \mid y) p_Y(y)\)
  • Independence Characterization: \(X \perp Y \iff p_{X|Y}(x \mid y) = p_X(x)\) for all \(x,y\)
  • Bayes' Theorem for Discrete RVs: \(p_{X|Y}(x \mid y) = \frac{p_{Y|X}(y \mid x) p_X(x)}{\sum_{x'} p_{Y|X}(y \mid x') p_X(x')}\)
