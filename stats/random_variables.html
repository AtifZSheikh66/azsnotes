📊 Random Variables

Formal definition, notation, fundamental theorems, Bernoulli and Characteristic random variables

1. Definition of a Random Variable

A random variable (RV) is a function \(X : \Omega \to \mathbb{R}\) that assigns a real number to each outcome \(\omega\) in the sample space \(\Omega\). It must be measurable, meaning that for every Borel set \(B \subseteq \mathbb{R}\), the preimage \(X^{-1}(B) = \{\omega \in \Omega : X(\omega) \in B\}\) is an event (belongs to the sigma-algebra \(\mathcal{F}\)).

Random variables allow us to work with numerical quantities derived from random experiments, rather than abstract outcomes. They are classified as:

  • Discrete Random Variables: Take values from a finite or countably infinite set (e.g., number of heads, dice roll)
  • Continuous Random Variables: Take values from an uncountably infinite set (e.g., height, temperature, time)
\[ X: \Omega \to \mathbb{R} \quad \text{such that} \quad X^{-1}(B) \in \mathcal{F} \; \forall B \in \mathcal{B}(\mathbb{R}) \]
✍️

2. Notation for Random Variables

Standard Notation:

  • Random variables are denoted by capital letters: \(X, Y, Z, T, \ldots\)
  • Their observed values (realizations) are denoted by lowercase letters: \(x, y, z, t, \ldots\)
  • \(P(X = x)\) — probability that RV \(X\) equals the value \(x\)
  • \(P(X \leq x)\) — cumulative distribution function (CDF) at \(x\)
  • \(P(X \in A)\) — probability that \(X\) falls in set \(A\)
  • \(F_X(x) = P(X \leq x)\) — CDF of \(X\)
  • \(f_X(x)\) — probability mass function (PMF) for discrete RVs
  • \(f_X(x)\) — probability density function (PDF) for continuous RVs
📖 Example: Tossing two fair coins. Let \(X\) = number of heads. Then:
\[ \Omega = \{HH, HT, TH, TT\}, \quad X(HH)=2, X(HT)=1, X(TH)=1, X(TT)=0 \]
\[ P(X=0) = \frac{1}{4}, \quad P(X=1) = \frac{1}{2}, \quad P(X=2) = \frac{1}{4} \]

3. Fundamental Theorems on Random Variables

📌 Theorem 1 (Properties of Cumulative Distribution Function)

For any random variable \(X\) with CDF \(F_X(x) = P(X \leq x)\), the following properties hold:

\[ \text{(i)} \quad \lim_{x \to -\infty} F_X(x) = 0 \]
\[ \text{(ii)} \quad \lim_{x \to \infty} F_X(x) = 1 \]
\[ \text{(iii)} \quad F_X \text{ is non-decreasing: } x_1 < x_2 \Rightarrow F_X(x_1) \leq F_X(x_2) \]
\[ \text{(iv)} \quad F_X \text{ is right-continuous: } \lim_{h \to 0^+} F_X(x+h) = F_X(x) \]

📝 Proof of (i):

Step 1 — Consider the event \(X \leq x\) as \(x \to -\infty\):

As \(x \to -\infty\), the event \(X \leq x\) becomes the empty set \(\emptyset\).

Step 2 — Apply continuity of probability:
\[ \lim_{x \to -\infty} F_X(x) = P(\emptyset) = 0 \]

📝 Proof of (ii):

Step 1 — Consider the event \(X \leq x\) as \(x \to \infty\):

As \(x \to \infty\), the event \(X \leq x\) becomes the entire sample space \(\Omega\).

Step 2 — Apply continuity of probability:
\[ \lim_{x \to \infty} F_X(x) = P(\Omega) = 1 \]

📝 Proof of (iii):

Step 1 — If \(x_1 < x_2\), then \(\{X \leq x_1\} \subseteq \{X \leq x_2\}\):

Because if \(X \leq x_1\), then automatically \(X \leq x_2\) since \(x_1 < x_2\).

Step 2 — Apply monotonicity of probability:
\[ F_X(x_1) = P(X \leq x_1) \leq P(X \leq x_2) = F_X(x_2) \]

📝 Proof of (iv) — Right-continuity:

Step 1 — Use the continuity of probability for a decreasing sequence:

Let \(h_n \downarrow 0\). Then the events \(\{X \leq x + h_n\}\) decrease to \(\{X \leq x\}\).

Step 2 — Apply continuity from above:
\[ \lim_{h \to 0^+} F_X(x+h) = P\left( \bigcap_{n=1}^{\infty} \{X \leq x + h_n\} \right) = P(X \leq x) = F_X(x) \]
📌 Corollary 1.1: \(P(a < X \leq b) = F_X(b) - F_X(a)\)
📌 Corollary 1.2: \(P(X = x) = F_X(x) - \lim_{t \to x^-} F_X(t)\) (the size of the jump at x)
📌 Corollary 1.3: For a continuous RV, \(P(X = x) = 0\) for all x.

📌 Theorem 2 (Properties of Expectation)

For random variables \(X\) and \(Y\) and constants \(a, b \in \mathbb{R}\):

\[ \text{(i)} \quad E[a] = a \quad \text{(Expectation of a constant)} \]
\[ \text{(ii)} \quad E[aX] = a E[X] \quad \text{(Homogeneity)} \]
\[ \text{(iii)} \quad E[X + Y] = E[X] + E[Y] \quad \text{(Additivity)} \]
\[ \text{(iv)} \quad E[aX + bY] = aE[X] + bE[Y] \quad \text{(Linearity)} \]

📝 Proof of (i):

\[ E[c] = \sum_{i} c \cdot P(X = c) = c \cdot 1 = c \]

📝 Proof of (ii):

\[ E[aX] = \sum_x a x \cdot P(X = x) = a \sum_x x P(X = x) = a E[X] \]

📝 Proof of (iii):

\[ E[X+Y] = \sum_x \sum_y (x+y) P(X=x, Y=y) = \sum_x x \sum_y P(X=x, Y=y) + \sum_y y \sum_x P(X=x, Y=y) \]
\[ = \sum_x x P(X=x) + \sum_y y P(Y=y) = E[X] + E[Y] \]

📝 Proof of (iv):

Combines (ii) and (iii): \(E[aX + bY] = aE[X] + bE[Y]\).

📌 Theorem 3 (Properties of Variance)

Variance is defined as \(\text{Var}(X) = E[(X - \mu)^2] = E[X^2] - (E[X])^2\). Properties:

\[ \text{(i)} \quad \text{Var}(c) = 0 \quad \text{(constant has zero variance)} \]
\[ \text{(ii)} \quad \text{Var}(aX) = a^2 \text{Var}(X) \]
\[ \text{(iii)} \quad \text{Var}(X + c) = \text{Var}(X) \]
\[ \text{(iv)} \quad \text{Var}(aX + b) = a^2 \text{Var}(X) \]

📝 Proof of (i):

\[ \text{Var}(c) = E[(c - E[c])^2] = E[(c - c)^2] = E[0] = 0 \]

📝 Proof of (ii):

\[ \text{Var}(aX) = E[(aX - E[aX])^2] = E[a^2(X - E[X])^2] = a^2 \text{Var}(X) \]

📝 Proof of (iii):

\[ \text{Var}(X + c) = E[(X + c - E[X + c])^2] = E[(X - E[X])^2] = \text{Var}(X) \]

📝 Proof of (iv):

\[ \text{Var}(aX + b) = a^2 \text{Var}(X) \]

4. Bernoulli Random Variable

A Bernoulli random variable is the simplest discrete random variable. It models a single trial of an experiment with exactly two outcomes: success (1) with probability \(p\), and failure (0) with probability \(q = 1-p\).

📌 Definition

Let \(X \sim \text{Bernoulli}(p)\), where \(0 \leq p \leq 1\). Then:

\[ P(X = 1) = p, \quad P(X = 0) = 1 - p \]

The probability mass function (PMF) is:

\[ f_X(x) = p^x (1-p)^{1-x}, \quad x \in \{0, 1\} \]

📌 Properties of Bernoulli Random Variable

\[ \text{(i) Expectation: } E[X] = p \]
\[ \text{(ii) Variance: } \text{Var}(X) = p(1-p) \]
\[ \text{(iii) Moment Generating Function: } M_X(t) = E[e^{tX}] = 1 - p + pe^t \]
\[ \text{(iv) Characteristic Function: } \phi_X(t) = E[e^{itX}] = 1 - p + pe^{it} \]

📝 Proof of (i) — Expectation:

\[ E[X] = 1 \cdot p + 0 \cdot (1-p) = p \]

📝 Proof of (ii) — Variance:

\[ E[X^2] = 1^2 \cdot p + 0^2 \cdot (1-p) = p \]
\[ \text{Var}(X) = E[X^2] - (E[X])^2 = p - p^2 = p(1-p) \]

📝 Proof of (iii) — MGF:

\[ M_X(t) = E[e^{tX}] = e^{t \cdot 1} \cdot p + e^{t \cdot 0} \cdot (1-p) = pe^t + (1-p) \]

📝 Proof of (iv) — Characteristic Function:

\[ \phi_X(t) = E[e^{itX}] = e^{it} p + (1-p) = 1 - p + pe^{it} \]
📌 Corollary 4.1 (Moment Generating Property):
\[ E[X^k] = p \quad \text{for all } k \geq 1 \]
📌 Corollary 4.2: Sum of \(n\) independent Bernoulli(p) random variables is a Binomial(n, p) random variable:
\[ Y = \sum_{i=1}^{n} X_i \sim \text{Binomial}(n, p) \]
📖 Example: Tossing a fair coin once. Let \(X = 1\) if heads (success), \(X = 0\) if tails (failure). Then \(X \sim \text{Bernoulli}(0.5)\). Expected number of heads = 0.5, variance = 0.5 × 0.5 = 0.25.
🏷️

5. Characteristic (Indicator) Random Variable

A characteristic random variable (also called an indicator random variable) is associated with an event \(A\) and takes the value 1 if the event occurs, and 0 otherwise. It is denoted as \(\mathbf{1}_A\) or \(I_A\).

📌 Definition

For any event \(A\), the indicator random variable is defined as:

\[ \mathbf{1}_A(\omega) = \begin{cases} 1 & \text{if } \omega \in A \\ 0 & \text{if } \omega \notin A \end{cases} \]

Note that \(\mathbf{1}_A \sim \text{Bernoulli}(P(A))\).

📌 Properties of Indicator Random Variables

\[ \text{(i) } \mathbf{1}_{A^c} = 1 - \mathbf{1}_A \]
\[ \text{(ii) } \mathbf{1}_{A \cap B} = \mathbf{1}_A \cdot \mathbf{1}_B \]
\[ \text{(iii) } \mathbf{1}_{A \cup B} = \mathbf{1}_A + \mathbf{1}_B - \mathbf{1}_A \mathbf{1}_B \]
\[ \text{(iv) } E[\mathbf{1}_A] = P(A) \]
\[ \text{(v) } \text{Var}(\mathbf{1}_A) = P(A)(1 - P(A)) \]
\[ \text{(vi) } \mathbf{1}_A \mathbf{1}_B = \mathbf{1}_{A \cap B} \]

📝 Proof of (i) — Complement:

\[ \mathbf{1}_{A^c}(\omega) = \begin{cases} 1 & \omega \notin A \\ 0 & \omega \in A \end{cases} = 1 - \mathbf{1}_A(\omega) \]

📝 Proof of (ii) — Intersection:

\[ \mathbf{1}_{A \cap B}(\omega) = 1 \iff \omega \in A \text{ and } \omega \in B \iff \mathbf{1}_A(\omega) = 1 \text{ and } \mathbf{1}_B(\omega) = 1 \iff \mathbf{1}_A(\omega) \cdot \mathbf{1}_B(\omega) = 1 \]

📝 Proof of (iii) — Union:

\[ \mathbf{1}_{A \cup B} = \mathbf{1}_A + \mathbf{1}_B - \mathbf{1}_A \mathbf{1}_B \quad \text{(by inclusion-exclusion)} \]

📝 Proof of (iv) — Expectation:

\[ E[\mathbf{1}_A] = 1 \cdot P(A) + 0 \cdot P(A^c) = P(A) \]

📝 Proof of (v) — Variance:

\[ \text{Var}(\mathbf{1}_A) = E[(\mathbf{1}_A)^2] - (E[\mathbf{1}_A])^2 = P(A) - (P(A))^2 = P(A)(1 - P(A)) \]
📌 Corollary 5.1 (Linearity of Expectation with Indicators):
\[ E\left[ \sum_{i=1}^{n} c_i \mathbf{1}_{A_i} \right] = \sum_{i=1}^{n} c_i P(A_i) \]
📌 Corollary 5.2 (Number of Events Occurring): Let \(N = \sum_{i=1}^{n} \mathbf{1}_{A_i}\) be the number of events that occur. Then:
\[ E[N] = \sum_{i=1}^{n} P(A_i) \]

📖 Example — Expectation of Number of Matches (Hat Check Problem):
In the matching problem with n hats, let \(\mathbf{1}_i\) be the indicator that person i gets their own hat. Then the number of matches \(N = \sum_{i=1}^{n} \mathbf{1}_i\). By linearity of expectation:
\[ E[N] = \sum_{i=1}^{n} E[\mathbf{1}_i] = \sum_{i=1}^{n} \frac{1}{n} = 1 \]
This elegant derivation shows the expected number of matches is always 1, independent of n!

6. Relationship Between Bernoulli and Characteristic RVs

Any Bernoulli random variable with parameter \(p\) can be expressed as an indicator of an event with probability \(p\). Conversely, any indicator random variable is a Bernoulli RV with parameter \(P(A)\).

\[ X \sim \text{Bernoulli}(p) \iff X = \mathbf{1}_A \text{ for some event } A \text{ with } P(A) = p \]
📌 Corollary 6.1: The sum of independent indicator RVs gives a Binomial RV.
📌 Corollary 6.2: Indicators are fundamental building blocks for counting random variables.

7. Summary: Bernoulli vs Characteristic Random Variables

Range{0, 1}{0, 1}

8. Practice Problems

Problem 1: For a Bernoulli random variable with \(p = 0.3\), find \(E[X]\), \(\text{Var}(X)\), and \(E[X^3]\).

Show Solution

\(E[X] = 0.3\), \(\text{Var}(X) = 0.3 \times 0.7 = 0.21\), \(E[X^3] = 1^3 \cdot 0.3 + 0^3 \cdot 0.7 = 0.3\)

Problem 2: For events A and B, express \(\mathbf{1}_{A \setminus B}\) in terms of \(\mathbf{1}_A\) and \(\mathbf{1}_B\).

Show Solution

\(\mathbf{1}_{A \setminus B} = \mathbf{1}_A - \mathbf{1}_A \mathbf{1}_B = \mathbf{1}_A (1 - \mathbf{1}_B)\)

Problem 3: Prove that \(\text{Var}(\mathbf{1}_A + \mathbf{1}_B) = \text{Var}(\mathbf{1}_A) + \text{Var}(\mathbf{1}_B) + 2\text{Cov}(\mathbf{1}_A, \mathbf{1}_B)\).

Show Solution

Use the general property \(\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X,Y)\).

📝 Summary: Key Takeaways

  • Random Variable: A measurable function from \(\Omega\) to \(\mathbb{R}\)
  • CDF Properties: Non-decreasing, right-continuous, limits 0 and 1 at ±∞
  • Expectation: Linear operator: \(E[aX+bY] = aE[X] + bE[Y]\)
  • Variance: \(\text{Var}(aX+b) = a^2\text{Var}(X)\); measures spread
  • Bernoulli(p): Models a single trial with success probability p. \(E[X]=p\), \(\text{Var}(X)=p(1-p)\)
  • Indicator RV \(\mathbf{1}_A\): Bernoulli with parameter \(P(A)\); fundamental for counting events
  • Key Application: Expectation of number of events = sum of probabilities (linearity of expectation)
