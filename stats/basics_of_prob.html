🎲 Basic Concepts of Probability

Foundations of uncertainty: Random experiments, sample spaces, events, and probability axioms

Probability Theory · Unit I
❓

1. What is Probability?

Probability is a branch of mathematics that quantifies uncertainty. It measures the likelihood that a particular event will occur, expressed as a number between 0 and 1 (or 0% to 100%)[citation:1].

A probability of 0 means an event is impossible, while a probability of 1 means an event is certain. Values between 0 and 1 represent degrees of uncertainty—for example, a fair coin has probability 0.5 (or 50%) of landing on heads[citation:1][citation:8].

📌 Key Insight: Probability is the mathematical language for describing and reasoning about randomness. It allows us to make precise statements about uncertain events, from coin flips to complex scientific phenomena.
🧪

2. Random Experiment

A random experiment is a process or procedure that produces an uncertain outcome, can be repeated indefinitely under the same conditions, and has a well-defined set of all possible outcomes[citation:2][citation:8].

Key characteristics of a random experiment:

  • Unpredictable in the short run — we cannot determine the outcome of a single trial with certainty
  • Predictable in the long run — the relative frequencies of outcomes stabilize over many trials (Law of Large Numbers)[citation:8]
  • Repeatable — the experiment can be performed many times under identical or similar conditions
📖 Examples of Random Experiments:
• Flipping a coin — possible outcomes: Heads (H) or Tails (T)
• Rolling a six-sided die — possible outcomes: 1, 2, 3, 4, 5, 6
• Drawing a card from a well-shuffled deck — possible outcomes: 52 different cards
• Measuring the height of a randomly selected person — possible outcomes: any real number within a range

Each performance of a random experiment is called a trial or repetition[citation:8].

🎯

3. Sample Space and Outcomes

The sample space (denoted by Ω or S) is the set of all possible outcomes of a random experiment[citation:3][citation:9].

Each element of the sample space is called an outcome or sample point. Outcomes are mutually exclusive—exactly one outcome occurs on each trial of the experiment[citation:9].

📖 Sample Space Examples:
• Coin toss: S = {H, T}
• Rolling a die: S = {1, 2, 3, 4, 5, 6}
• Flipping two coins: S = {HH, HT, TH, TT}
• Drawing a card: S = {Ace of Hearts, 2 of Hearts, ..., King of Spades}

Sample spaces can be:

  • Finite — limited number of outcomes (e.g., coin toss, die roll)
  • Countably infinite — infinite but can be listed (e.g., number of coin tosses until first heads)
  • Uncountably infinite — infinite and cannot be listed (e.g., measuring height or time)
📋

4. Events

An event is a subset of the sample space — a collection of one or more outcomes[citation:9][citation:10].

An event occurs if the outcome of the experiment is an element of that event. Events allow us to discuss meaningful collections of outcomes rather than just individual results.

Types of Events

  • Simple (Elementary) Event: An event containing exactly one outcome[citation:9]. Example: rolling a 3 on a die → A = {3}
  • Compound Event: An event containing two or more outcomes. Example: rolling an even number → B = {2, 4, 6}
  • Certain Event: The event that always occurs, equal to the entire sample space S
  • Impossible Event: The event that never occurs, represented by the empty set ∅[citation:6]
📖 Event Examples (Two Coin Flips):
Sample Space: S = {HH, HT, TH, TT}
• Event A = "At least one head" = {HH, HT, TH}
• Event B = "Same faces" = {HH, TT}
• Event C = "Three heads" = ∅ (impossible with two coins)

6. Definitions of Probability

Throughout history, probability has been defined in several ways. Each approach has its own strengths and limitations.

📊 Classical Definition (Laplace, 1812)

P(A) = (Number of favorable outcomes) / (Total number of possible outcomes)

This definition assumes all outcomes are equally likely[citation:4].

Example: Probability of rolling an even number on a fair die = 3/6 = 0.5

Limitation: Only applies when outcomes are equally likely; cannot handle biased coins or real-world events where outcomes have different probabilities[citation:2].

📈 Relative Frequency (Statistical) Definition

P(A) = limn→∞ (number of times A occurs / n)

Probability equals the limiting relative frequency of an event as the number of trials approaches infinity[citation:4][citation:8].

Example: After flipping a coin 10,000 times, if heads appears 4,987 times, the relative frequency is ≈ 0.4987. As trials increase, this value approaches the true probability (0.5 for a fair coin).

Limitation: Requires repeatable experiments; cannot assign probability to one-time events (e.g., "Will it rain tomorrow?").

📚 Axiomatic Definition (Kolmogorov, 1933)

The modern foundation of probability theory. Probability is defined as a function P that assigns numbers to events satisfying three axioms[citation:5].

Advantage: No assumptions about equally likely outcomes; applies universally. This is the standard approach used in modern probability theory[citation:3].

📜

7. Kolmogorov's Axioms of Probability

Introduced by Russian mathematician Andrey Kolmogorov in 1933, these three axioms form the foundation of modern probability theory[citation:5].

Axiom 1: Non-negativity

P(E) ≥ 0

The probability of any event E is a non-negative real number[citation:5].

Axiom 2: Unit Measure

P(S) = 1

The probability of the entire sample space (some outcome occurring) is 1 or 100%[citation:5].

Axiom 3: σ-additivity (Countable Additivity)

P(⋃i=1∞ Ei) = Σi=1∞ P(Ei)

For any countable sequence of mutually exclusive events E₁, E₂, E₃, ... , the probability of their union equals the sum of their individual probabilities[citation:5].

📌 The Power of Axioms: From these three simple axioms, all of probability theory can be derived—including the addition rule, complement rule, and more complex theorems. This makes the axioms both elegant and powerful[citation:5][citation:7].
⚙️

8. Fundamental Probability Theorems

These corollaries follow directly from the axioms and are essential for calculations[citation:5][citation:7].

Complement Rule

P(Aᶜ) = 1 - P(A)

The probability that an event does NOT occur is 1 minus the probability that it does occur.

Addition Rule (Union of Events)

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

For mutually exclusive events (A ∩ B = ∅), this simplifies to: P(A ∪ B) = P(A) + P(B)[citation:5].

📖 Example: Drawing a card from a deck. Let A = "Heart", B = "King". P(A) = 13/52, P(B) = 4/52, P(A ∩ B) = 1/52 (King of Hearts).
P(A ∪ B) = 13/52 + 4/52 - 1/52 = 16/52 ≈ 0.3077

Numeric Bound

0 ≤ P(E) ≤ 1

Probabilities always lie between 0 and 1 (inclusive)[citation:5][citation:7].

Probability of the Empty Set

P(∅) = 0

The probability of an impossible event is zero[citation:5].

📊

9. Law of Large Numbers (LLN)

Proved by Jacob Bernoulli in the 18th century, the Law of Large Numbers provides the theoretical foundation for the frequency interpretation of probability[citation:8].

As the number of trials n increases, the relative frequency of an event converges (in probability) to its true probability.
📖 Illustration: Flipping a fair coin:
• After 10 flips: 7 heads (70%) — not close to 0.5
• After 100 flips: 52 heads (52%) — closer
• After 1,000 flips: 498 heads (49.8%) — even closer
• After 10,000 flips: 5,012 heads (50.12%) — very close to 0.5
💡 Important: The LLN requires identical distribution (same probability each trial) and independence (outcomes don't affect each other)[citation:8]. This justifies why we can estimate probabilities from observed frequencies.

📝 Summary: Core Concepts to Remember

  • Probability measures uncertainty on a scale from 0 (impossible) to 1 (certain)
  • A random experiment is repeatable with uncertain outcomes
  • The sample space contains all possible outcomes
  • Events are subsets of the sample space
  • Three probability interpretations exist: Classical (equally likely), Relative Frequency (long-run), Axiomatic (Kolmogorov's axioms)
  • Kolmogorov's three axioms (non-negativity, unit measure, additivity) form the foundation of modern probability theory
  • Key theorems include complement rule, addition rule, and Law of Large Numbers
